## 一、今日工作概述

今日工作围绕股票关联网络的实证实践展开，重点完成了从股票价格数据到股票关联网络构建与分析的完整流程。研究对象为 **15 只股票**，使用 **2023 年 1 月至 2026 年 7 月** 的前复权日收盘价数据。

整体工作流程为：

\[
\boxed{
\text{前复权价格}
\rightarrow
\text{对数收益率}
\rightarrow
\text{Pearson相关矩阵}
\rightarrow
\text{阈值相关网络}
\rightarrow
\text{MST}
\rightarrow
\text{网络中心性与行业结构分析}
}
\]

今日实践的核心目标是理解如何将股票收益的统计相关关系转换为网络结构，并进一步解释网络中节点、边及行业聚集所包含的金融含义。

## 二、股票价格数据整理与质量控制

### 1. 数据内容

构建了由 15 只股票组成的股票池，并整理其前复权日收盘价数据。股票覆盖多个行业，以便后续观察股票关联网络中是否存在行业聚集现象。

数据采用统一的前复权口径，以减少分红、送股、拆股等公司行为引起的价格跳跃对收益率计算的影响。

### 2. 数据结构

最终形成以交易日为行、股票代码为列的价格矩阵：

\[
P=
\begin{pmatrix}
P_{1,1} & \cdots & P_{1,p}\\
\vdots & & \vdots\\
P_{T,1} & \cdots & P_{T,p}
\end{pmatrix},
\]

其中：

- \(T\) 表示交易日数量；
- \(p=15\) 表示股票数量；
- \(P_{t,i}\) 表示股票 \(i\) 在交易日 \(t\) 的前复权价格。

同时整理了股票代码、股票名称和行业信息，为后续网络节点标注与行业分类提供基础。

### 3. 数据质量检查

对数据进行了以下检查：

- 日期排序；
- 重复交易日检查；
- 缺失值检查；
- 股票观测覆盖率检查；
- 非正价格检查；
- 股票代码格式统一。

通过上述步骤，确保后续收益率计算与网络分析使用一致、完整的数据基础。

## 三、对数收益率与相关矩阵计算

### 1. 对数收益率计算

对于股票 \(i\)，定义日对数收益率为：

\[
\boxed{
r_{i,t}
=
\ln\left(
\frac{P_{i,t}}
{P_{i,t-1}}
\right)
}
\]

其中 \(\ln(\cdot)\) 为以 \(e\) 为底的自然对数。

等价地：

\[
r_{i,t}
=
\ln P_{i,t}
-
\ln P_{i,t-1}.
\]

由于第一个交易日不存在上一期价格，因此无法计算第一期收益率。

在当前数据中，共有 866 个交易日，因此每只股票最终得到 865 个日对数收益率。

### 2. 对数收益率的金融解释

对数收益率的正负分别表示：

\[
r_{i,t}>0
\Rightarrow
\text{股票上涨},
\]

\[
r_{i,t}<0
\Rightarrow
\text{股票下跌}.
\]

相对于直接使用股票价格，对数收益率主要反映股票的单期相对价格变化，并在较大程度上消除了股票价格水平和长期趋势差异，更适合用于研究股票之间的同期共同波动关系。

此外，对数收益率具有时间可加性：

\[
\ln\frac{P_T}{P_0}
=
\sum_{t=1}^{T}
\ln\frac{P_t}{P_{t-1}}.
\]

### 3. Pearson 相关矩阵

在对数收益率基础上，计算股票两两之间的 Pearson 相关系数：

\[
\boxed{
\rho_{ij}
=
\operatorname{Corr}
(r_i,r_j)
}
\]

并得到一个 \(15\times15\) 的股票收益相关矩阵。

该矩阵反映不同股票日收益率之间的同步程度，是后续构建股票关联网络的核心输入。

### 4. 相关矩阵的初步解释

相关系数越大，表示两只股票收益率越倾向于同方向波动。

需要注意：

\[
\boxed{
\text{相关关系不等于因果关系}
}
\]

较高相关性可能来自：

- 市场共同因子；
- 行业共同因子；
- 风格因子；
- 宏观环境；
- 其他共同冲击。

因此当前构建的是“收益相关网络”，而非直接依赖网络或因果网络。

## 四、阈值相关网络构建

### 1. 阈值网络定义

完整相关矩阵中 15 只股票共有：

\[
\binom{15}{2}
=
105
\]

个潜在股票对。

若全部保留，则网络过于稠密，因此采用阈值方法进行过滤。

定义：

\[
A_{ij}
=
\mathbf{1}
\{
\rho_{ij}\geq\tau
\}.
\]

今日实践采用：

\[
\boxed{
\tau=0.5
}
\]

作为初步阈值。

因此：

\[
\rho_{ij}\geq0.5
\]

时，在股票 \(i\) 与股票 \(j\) 之间保留一条边。

### 2. 阈值网络边权

阈值相关网络的边权定义为：

\[
\boxed{
w_{ij}=\rho_{ij}
}
\]

即相关系数本身。

因此网络中同时包含两类信息：

- 是否存在边：判断相关性是否超过阈值；
- 边权大小：反映被保留关系的强弱。

### 3. 边宽设计

为了增强可视化效果，使不同股票对的相关性强弱更加直观，将边宽设置为相关系数的单调增函数，例如：

\[
\operatorname{width}_{ij}
=
a+b\rho_{ij}.
\]

因此：

\[
\boxed{
\rho_{ij}\uparrow
\Rightarrow
\text{边越粗}
}
\]

从图像上可以直接识别相关性较强的股票关系。

### 4. 边权标签

在阈值相关网络图中直接标注：

\[
\rho_{ij}
\]

作为边标签，使网络图能够同时展示“连接关系”和“具体相关强度”。

### 5. 阈值敏感性分析

进一步比较了不同阈值下网络边数量的变化，例如：

\[
\tau
\in
\{0.3,0.4,0.5,0.6\}.
\]

该分析用于说明阈值网络具有一定的人为参数依赖性：

- 阈值较低时，网络较稠密；
- 阈值较高时，网络较稀疏；
- 过高阈值可能产生孤立节点；
- 过低阈值可能保留大量弱相关边。

因此阈值网络适合作为直观的关联关系过滤方法，但阈值选择本身是一个需要进一步研究的问题。

## 五、最小生成树（MST）构建

### 1. 从相关系数转换为相关距离

MST 使用距离而非相似度，因此将 Pearson 相关系数转换为 Mantegna 相关距离：

\[
\boxed{
d_{ij}
=
\sqrt{
2(1-\rho_{ij})
}
}
\]

其性质为：

\[
\rho_{ij}\uparrow
\Longleftrightarrow
d_{ij}\downarrow.
\]

例如：

\[
\rho_{ij}=1
\Rightarrow
d_{ij}=0,
\]

而：

\[
\rho_{ij}=0
\Rightarrow
d_{ij}=\sqrt{2}.
\]

因此相关性越强，两只股票之间的相关距离越短。

### 2. MST 的数学含义

MST 在完整股票网络中寻找一棵生成树：

\[
\boxed{
T^*
=
\arg\min_T
\sum_{(i,j)\in T}
d_{ij}
}
\]

同时满足：

- 所有股票节点均连通；
- 网络中不存在环；
- 总相关距离最小。

对于 \(p=15\) 只股票，MST 必然包含：

\[
p-1
=
14
\]

条边。

因此 MST 可以被理解为：

> 在保证所有股票均连通的条件下，保留股票相关结构的最简骨架。

### 3. MST 的边权

MST 中将边权定义为：

\[
\boxed{
w_{ij}=d_{ij}
}
\]

并在网络图中直接显示相关距离。

因此：

\[
\boxed{
\text{边权越小}
\Rightarrow
\text{相关性越强}
}
\]

### 4. 按相关距离绘制边长

进一步修改了常规 `spring_layout` 的绘图方式，使 MST 中每一条直接连接边的几何长度满足：

\[
\boxed{
L_{ij}
=
c\,d_{ij}
}
\]

其中 \(c\) 为统一缩放常数。

由此得到：

\[
\boxed{
\text{边越短}
\Longleftrightarrow
d_{ij}\text{ 越小}
\Longleftrightarrow
\rho_{ij}\text{ 越大}
}
\]

这使 MST 图像中的边长具有明确的统计含义，而不仅仅是普通网络布局产生的视觉距离。

### 5. MST 边宽

虽然 MST 的边权采用相关距离，但为了更直观地展示相关性强弱，边宽仍按照相关系数进行设置：

\[
\operatorname{width}_{ij}
=
a+b\rho_{ij}.
\]

因此：

\[
\boxed{
\text{短且粗的边}
=
\text{相关性较强的股票关系}
}
\]

### 6. MST 中节点方向的解释

进一步明确：

- MST 中边的长度可以被赋予相关距离含义；
- 节点处于左、右、上、下等绝对方向通常不具有金融含义；
- 节点方向主要服务于图形布局和减少重叠；
- 真正有解释意义的是连接关系、边权、边长和拓扑位置。

同时，距离保持型 MST 仅保证：

\[
(i,j)\in E_{\mathrm{MST}}
\]

的直接连接边长度与 \(d_{ij}\) 成比例。

对于没有直接相连的两个节点，其二维图像中的欧氏距离不能直接解释为原始相关距离。

## 七、节点中心性分析

从“网络构建”进一步进入“网络解释”。

主要研究哪些股票在网络结构中处于较重要位置。

### 1. Degree

定义：

\[
d_i
=
\sum_{j\neq i}
A_{ij}.
\]

在阈值相关网络中，Degree 表示：

> 股票 \(i\) 与多少只股票存在超过阈值的强相关关系。

Degree 越大，说明该股票拥有更多强相关邻居。

---

### 2. Weighted Degree

考虑边权后定义：

\[
\boxed{
s_i
=
\sum_{j:(i,j)\in E}
\rho_{ij}
}
\]

其同时考虑：

- 邻居数量；
- 相关关系强度。

因此：

\[
\boxed{
\text{Degree}
\rightarrow
\text{强关联数量}
}
\]

而：

\[
\boxed{
\text{Weighted Degree}
\rightarrow
\text{总体关联强度}
}
\]

---

### 3. Betweenness Centrality

Betweenness 定义为：

\[
C_B(i)
=
\sum_{s\neq i\neq t}
\frac{
\sigma_{st}(i)
}{
\sigma_{st}
}.
\]

其用于衡量某只股票是否经常位于其他股票之间的最短路径上。

Betweenness 较高意味着该节点可能在当前网络结构中承担较明显的桥梁作用。

尤其在 MST 中，高 Betweenness 节点通常连接多个网络分支。

但需要注意：

\[
\boxed{
\text{高 Betweenness 不等于因果意义上的风险传播中心}
}
\]

它首先是一个网络拓扑指标。

---

### 4. Closeness Centrality

基于相关距离计算：

\[
C_C(i)
=
\frac{1}
{\sum_j d(i,j)}.
\]

Closeness 较高意味着该节点从网络路径角度看总体更接近其他股票。

---

## 八、MST 中心—外围结构

由于 MST 是一棵树，因此可以进一步识别：

### 1. 叶节点

若：

\[
d_i=1,
\]

则称其为：

\[
\boxed{
\text{Leaf Node}
}
\]

即 MST 中的外围节点。

### 2. 分支节点

若：

\[
d_i\geq3,
\]

则说明该节点连接多个网络分支，可以被视为 MST 骨架中的重要分支节点。

### 3. 桥梁节点

结合 Betweenness，可以进一步识别连接不同局部股票群的桥梁节点。

因此可以从 MST 中形成：

\[
\boxed{
\text{核心/分支节点}
\rightarrow
\text{桥梁节点}
\rightarrow
\text{外围节点}
}
\]

的结构性认识。

## 九、行业聚集分析

除了节点颜色的定性观察，进一步设计了行业结构的定量分析。

### 1. 同行业边比例

定义：

\[
R_{\mathrm{same}}
=
\frac{
\#\{\text{同行业连接边}\}
}{
\#\{\text{全部网络边}\}
}.
\]

该指标用于衡量网络中的边有多大比例连接同行业股票。

### 2. Industry Assortativity

进一步使用行业属性的 assortativity coefficient 衡量网络的同类连接倾向。

一般而言：

\[
r_{\mathrm{industry}}>0
\]

表示股票更倾向与同行业股票连接；

\[
r_{\mathrm{industry}}\approx0
\]

表示行业属性与连接关系之间没有明显的同类偏好；

\[
r_{\mathrm{industry}}<0
\]

表示网络更倾向跨行业连接。

由于当前仅包含 15 只股票，该指标主要作为描述性结果，不宜进行过强的统计推断。

## 十、阈值网络与 MST 的差异理解

今日实践进一步明确了两类网络的核心区别。

### 阈值相关网络

\[
E_\tau
=
\{
(i,j):
\rho_{ij}\geq\tau
\}.
\]

其回答：

> 哪些股票之间的收益相关性达到预设的“强关联”标准？

因此 Degree 等指标具有较直接的“强相关股票数量”含义。

### MST

MST 回答：

> 如何从完整相关结构中选择 \(p-1\) 条边，使全部股票连通且总相关距离最小？

MST 会主动删除部分冗余的高相关边，以避免形成环。

因此：

\[
\boxed{
\text{MST 中没有直接连接}
\not\Rightarrow
\text{两只股票不相关}
}
\]

MST 中的中心性主要反映股票在“最简相关骨架”中的拓扑角色，而不是其在完整市场中的所有相关关系。

## 十二、今日解决的主要问题

今日实践过程中重点解决和澄清了以下问题：

1. 明确股票关联网络应以收益率而非原始价格水平作为基础构建；
2. 明确对数收益率使用自然对数：
   \[
   \ln(\cdot)=\log_e(\cdot);
   \]
3. 理解阈值网络中“是否有边”与“边权强度”的区别；
4. 明确阈值网络边权可以直接使用 Pearson 相关系数；
5. 理解 MST 不能直接把相关系数作为距离，而需要进行：
   \[
   \rho_{ij}
   \rightarrow
   d_{ij}
   =
   \sqrt{2(1-\rho_{ij})};
   \]
6. 明确 MST 中相关性越强对应相关距离越短；
7. 将 MST 的实际绘图边长设置为与相关距离成比例；
8. 明确普通 `spring_layout` 图中的视觉边长本身没有统计含义；
9. 明确 MST 节点的绝对方向通常没有金融意义；
10. 使用边宽进一步强化相关性强弱的视觉差异；
11. 使用行业颜色区分不同股票行业；
12. 进入 Degree、Weighted Degree、Betweenness 和 Closeness 等网络指标分析；
13. 明确相关网络不代表因果网络，相关性可能来自市场、行业和风格等共同因子。

在完成基础相关网络实践后，下一步可以围绕“原始相关关系是否是真正的直接股票关联”展开。

推荐按照以下路线继续：

\[
\boxed{
\text{Pearson相关网络}
\rightarrow
\text{偏相关网络}
\rightarrow
\text{精度矩阵网络}
\rightarrow
\text{因子调整后的残差网络}
}
\]

重点研究：

1. 市场共同因子是否造成大量表面相关关系；
2. 行业共同因子是否解释同行业股票的高相关；
3. 控制其他股票后，哪些股票之间仍存在直接条件相关关系；
4. 使用 Graphical Lasso、CLIME 等方法估计高维稀疏关联网络；
5. 比较原始相关网络与条件依赖网络的拓扑差异；
6. 后续扩展到滚动窗口，研究股票关联网络随时间的动态变化。
