# 2026-08-13 股票关联网络工作总结

## 一、今日工作主题

今日工作围绕股票关联网络从“边际相关”向“条件关联”推进，核心研究问题为：

> **在控制其余股票的线性信息后，Pearson 相关网络中观察到的强关联是否仍然存在？**

在昨日完成 Pearson 相关矩阵、Pearson 阈值网络与 MST 网络分析的基础上，今日进一步引入样本协方差矩阵、精度矩阵和偏相关矩阵，并构建偏相关网络，为后续研究条件依赖网络、稀疏精度矩阵估计与 Graphical Lasso 奠定基础。

今日整体技术路线为：

\[
\text{对数收益率}
\rightarrow
\widehat{\Sigma}
\rightarrow
\widehat{\Omega}=\widehat{\Sigma}^{-1}
\rightarrow
\widehat P_{\mathrm{partial}}
\rightarrow
\text{偏相关网络}
\rightarrow
\text{与 Pearson 阈值网络比较}.
\]

## 二、阶段一：明确 Pearson 相关与偏相关的研究差异

首先对昨日 Pearson 相关网络的统计含义进行了重新梳理。

Pearson 相关系数

\[
\rho_{ij}=\operatorname{Corr}(r_i,r_j)
\]

衡量两只股票收益率之间的边际线性共同波动，但其中可能同时包含市场共同波动、行业共同波动以及其他股票所代表的共同信息。

因此，Pearson 网络中的一条强边不能直接解释为两只股票之间存在“直接关系”。

今日进一步考虑偏相关系数

\[
\rho_{ij\mid -ij},
\]

其目标是在控制其余股票线性影响后，衡量股票 \(i\) 与股票 \(j\) 之间剩余的线性关联。

由此明确了今日核心问题：

\[
\boxed{
\text{哪些 Pearson 强相关关系在控制其他股票以后仍然保持？}
}
\]

同时进一步明确：

- Pearson correlation：边际线性关联；
- Partial correlation：控制其他变量后的条件线性关联；
- Partial correlation 不等同于因果关系；
- 只有在多元高斯等适当假设下，精度矩阵的零元素才能进一步解释为条件独立结构。

## 三、阶段二：计算样本协方差矩阵

基于前一日获得的 15 只股票日对数收益率数据，计算样本协方差矩阵。

设收益率向量为

\[
\mathbf r_t=(r_{1t},\ldots,r_{pt})^\top,
\]

样本协方差矩阵定义为

\[
\widehat{\Sigma}
=
\frac{1}{n-1}
\sum_{t=1}^{n}
(\mathbf r_t-\bar{\mathbf r})
(\mathbf r_t-\bar{\mathbf r})^\top.
\]

对于当前 \(p=15\) 只股票，

\[
\widehat{\Sigma}\in\mathbb R^{15\times15}.
\]

其中：

\[
\widehat{\Sigma}_{ii}
=
\widehat{\operatorname{Var}}(r_i)
\]

表示第 \(i\) 只股票收益率的样本方差；

\[
\widehat{\Sigma}_{ij}
=
\widehat{\operatorname{Cov}}(r_i,r_j)
\]

表示股票 \(i,j\) 收益率之间的样本协方差。

在代码实现中，对收益率数据进行了完整样本处理，并检查协方差矩阵的对称性、秩、特征值和条件数，为下一阶段计算逆协方差矩阵做好数值准备。

阶段二核心输出：

```text
stock_covariance.csv
```

## 四、阶段三：计算精度矩阵与偏相关矩阵

### 1. 精度矩阵

在样本协方差矩阵基础上定义精度矩阵：

\[
\widehat{\Omega}
=
\widehat{\Sigma}^{-1}.
\]

精度矩阵与协方差矩阵所包含的信息不同：协方差矩阵主要刻画变量的边际共同变化，而精度矩阵包含控制其他变量后的条件关系信息。

代码中进一步验证

\[
\widehat{\Sigma}\widehat{\Omega}\approx I,
\]

用于检查求逆结果的数值正确性。

阶段输出：

```text
precision_matrix.csv
```

### 2. 偏相关矩阵

利用精度矩阵计算控制其余股票后的偏相关系数：

\[
\boxed{
\widehat\rho_{ij\mid-rest}
=
-
\frac{\widehat\Omega_{ij}}
{\sqrt{\widehat\Omega_{ii}\widehat\Omega_{jj}}}
}
\]

并将对角线统一设置为 1。

公式中的负号来源于协方差矩阵求逆时二维条件协方差块的非对角元素发生符号反转，而不是人为加入的符号。

阶段输出：

```text
partial_correlation.csv
```

由此完成了从

\[
\widehat{\Sigma}
\rightarrow
\widehat{\Omega}
\rightarrow
\widehat P_{\mathrm{partial}}
\]

的完整计算过程。

## 五、阶段四：比较 Pearson 相关矩阵与偏相关矩阵

本阶段针对 15 只股票的

\[
\binom{15}{2}=105
\]

个不同股票对，逐一比较 Pearson 相关系数与偏相关系数。

重点构造以下指标。

### 1. 有符号变化

\[
\Delta_{ij}
=
\rho^{\mathrm{Partial}}_{ij}
-
\rho^{\mathrm{Pearson}}_{ij}.
\]

用于分析关联方向和数值的变化。

### 2. 关联强度衰减

\[
A_{ij}
=
|\rho^{\mathrm{Pearson}}_{ij}|
-
|\rho^{\mathrm{Partial}}_{ij}|.
\]

若 \(A_{ij}>0\)，表示控制其余股票后，两只股票之间的关联强度下降。

### 3. 关联强度保留比例

\[
Q_{ij}
=
\frac{
|\rho^{\mathrm{Partial}}_{ij}|
}{
|\rho^{\mathrm{Pearson}}_{ij}|
}.
\]

用于衡量原始 Pearson 关联在控制其他股票后仍保留多少。

### 4. 当前数据的主要结果

根据今日得到的 Pearson 与 Partial 两个矩阵，105 个股票对表现出非常明显的整体衰减特征：

\[
\operatorname{mean}(|\rho^{\mathrm{Pearson}}|)
\approx 0.337,
\]

而

\[
\operatorname{mean}(|\rho^{\mathrm{Partial}}|)
\approx 0.083.
\]

其中位数分别约为

\[
0.319
\quad\text{和}\quad
0.045.
\]

在当前样本中，105 个股票对均满足

\[
|\rho^{\mathrm{Partial}}_{ij}|
<
|\rho^{\mathrm{Pearson}}_{ij}|.
\]

这一现象不是偏相关的一般数学定理，而是当前股票样本呈现出的经验特征。

结果说明，原 Pearson 相关矩阵中的大量边际共同波动在控制其余股票线性信息后明显减弱，表明原始股票相关结构中包含较强的共同结构或间接关联成分。

同时，部分股票对在控制其他股票以后仍保持较高偏相关，这类关系更加值得在后续条件关联网络中重点关注。

## 六、阶段五：构建偏相关网络

在阶段四完成矩阵层面的比较后，进一步将偏相关矩阵转换为网络。

偏相关网络定义为

\[
G_{\mathrm{PC}}=(V,E_{\mathrm{PC}}),
\]

其中节点为股票，边按照绝对偏相关阈值确定：

\[
(i,j)\in E_{\mathrm{PC}}
\iff
|\rho_{ij\mid-rest}|
\ge \tau_{\mathrm{PC}}.
\]

与昨日 Pearson 阈值网络只关注强正相关不同，偏相关网络同时保留正、负条件线性关联，因此边筛选使用

\[
|\rho_{ij\mid-rest}|.
\]

网络中：

- 节点表示股票；
- 节点颜色表示行业；
- 边宽随 \(|\rho_{ij\mid-rest}|\) 增加；
- 实线表示正偏相关；
- 虚线表示负偏相关；
- 边标签显示带符号的偏相关系数。

由于偏相关整体数值明显小于 Pearson 相关，不宜机械沿用 Pearson 网络的 \(0.5\) 阈值。因此对

\[
\tau_{\mathrm{PC}}
\in
\{0.05,0.10,0.15,0.20,0.25,0.30\}
\]

进行阈值敏感性分析，并将 \(0.20\) 作为当前实践中的工作阈值候选。

需要强调：

\[
\tau_{\mathrm{PC}}=0.20
\]

属于当前探索性分析中的描述性阈值，并不是统计显著性临界值。

阶段五主要输出设计为：

## 七、阶段六：偏相关网络与昨日 Pearson 阈值网络比较

本阶段不重新计算或重新绘制两个单独网络，而是直接读取昨日已经保存的 Pearson 阈值网络边表与今日偏相关网络边表。

核心比较对象为两个边集：

\[
E_{\mathrm P}
=
\text{Pearson 阈值网络边集},
\]

\[
E_{\mathrm{PC}}
=
\text{偏相关网络边集}.
\]

重点分析以下三类边。

### 1. 两个网络共同保留的边

\[
E_{\mathrm P}\cap E_{\mathrm{PC}}.
\]

这类股票对既表现出较强边际相关，又在控制其他股票以后保持较明显的条件线性关联，可以视为相对稳健的关联关系。

### 2. 仅 Pearson 网络存在的边

\[
E_{\mathrm P}\setminus E_{\mathrm{PC}}.
\]

这类股票对原本具有较强边际共同波动，但控制其他股票后未能继续达到偏相关网络阈值，提示原相关关系中可能包含较强的共同结构或间接关联成分。

### 3. 仅偏相关网络存在的边

\[
E_{\mathrm{PC}}\setminus E_{\mathrm P}.
\]

这类关系在原 Pearson 强相关网络中并不突出，但控制其他股票后具有相对明显的剩余条件关联。

进一步使用 Jaccard similarity：

\[
J
=
\frac{
|E_{\mathrm P}\cap E_{\mathrm{PC}}|
}{
|E_{\mathrm P}\cup E_{\mathrm{PC}}|
}
\]

衡量两个网络边结构的相似程度，并使用 Pearson edge retention：

\[
R_{\mathrm P}
=
\frac{
|E_{\mathrm P}\cap E_{\mathrm{PC}}|
}{
|E_{\mathrm P}|
}
\]

衡量昨日 Pearson 强相关边在控制其他股票后仍被保留的比例。

此外，还设计比较：

- Network density；
- Connected components；
- Isolated nodes；
- Degree；
- Strength；
- Betweenness；
- Closeness；
- 同行业边比例；
- Industry assortativity。

阶段六不再重复绘制 Pearson 与 Partial 两个单独网络，只建议新增一张“网络边变化图”，直接展示：

- 两个网络共同边；
- Pearson-only 边；
- Partial-only 边。

主要输出设计为：


## 八、今日工作的主要认识

今日工作的核心进展是将股票关联网络从“边际相关结构”推进到了“条件线性关联结构”。

昨日主要回答：

\[
\boxed{
\text{哪些股票一起波动？}
}
\]

今日进一步回答：

\[
\boxed{
\text{控制其他股票以后，哪些股票关系仍然存在？}
}
\]

当前矩阵结果已经显示，偏相关系数整体远小于 Pearson 相关系数，说明大量股票边际相关能够被股票池中的其他线性信息解释。

因此，Pearson 相关网络更适合描述市场中的总体共同波动结构，而偏相关网络能够进一步压缩共同结构影响，突出较为直接的条件线性关联。

但需要保持以下解释边界：

1. 偏相关不等于因果关系；
2. 控制其余股票不等于显式剔除市场因子或行业因子；
3. 直接逆协方差矩阵一般不会产生严格稀疏结构；
4. 当前偏相关网络阈值属于探索性选择；
5. 若后续研究高维股票池，需要进一步考虑正则化精度矩阵估计。
