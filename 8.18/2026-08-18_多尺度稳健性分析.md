# 2026-08-18 工作总结

## 一、今日研究主题

**动态股票关联网络的多时间尺度稳健性、边生命周期、节点角色稳定性与“稳定行业核心 + 动态跨行业外围”综合验证**

今日在前一阶段 Rolling Graphical Lasso 动态股票关联网络研究的基础上，进一步围绕动态网络结果是否对时间窗口长度敏感、哪些边是真正跨尺度稳定、非核心边的动态变化属于阶段性还是频繁跳动、节点中心角色是否稳定，以及“稳定行业核心 + 动态跨行业外围”这一结构性发现能否在多项指标下获得一致支持等问题展开系统分析。

---

## 二、今日主要研究目标

今日工作主要围绕以下五个阶段展开：

1. **Window-size Sensitivity**：比较不同滚动窗口长度下网络结构和动态特征是否稳定；
2. **Multi-scale Persistence**：识别在半年、一年、两年多个时间尺度下均稳定存在的核心边；
3. **Edge Lifecycle**：区分低/中 Persistence 边是阶段性持续，还是频繁进入退出网络；
4. **Dynamic Centrality Stability**：研究股票节点在动态网络中的中心角色是否稳定；
5. **Integrated Validation**：综合验证“稳定行业核心 + 动态跨行业外围”的结构性结论。

# 三、阶段二：Window-size Sensitivity

## 3.1 实验设计

在保持其他设定不变的条件下，仅改变 Rolling Window 长度：

\[
W\in\{126,252,504\},
\]

其中：

- \(W=126\)：约半年交易日；
- \(W=252\)：约一年交易日；
- \(W=504\)：约两年交易日。

固定：

\[
STEP=20,
\]

以及前期选定的 Graphical Lasso 正则化参数：

\[
\alpha=\alpha_{1SE}\approx0.2169.
\]

为保证不同 Window Size 之间具有可比性，三个窗口长度均限定在相同的 18 个 network dates 上进行比较，时间范围为：

\[
2025\text{-}02\text{-}19
\sim
2026\text{-}07\text{-}14.
\]

---

## 3.2 主要结果

### （1）窗口越长，网络越稠密

三个时间尺度下平均边数分别为：

\[
44.17,\quad48.50,\quad54.72.
\]

对应平均网络密度为：

\[
0.421,\quad0.462,\quad0.521.
\]

因此，在固定 \(\alpha\) 的情况下：

\[
\boxed{
W\uparrow
\Rightarrow
\text{网络更稠密}.
}
\]

同时，平均被选中边的绝对 Partial Correlation 为：

\[
0.1269,\quad0.1206,\quad0.1098.
\]

说明长窗口虽然得到更多边，但新增关系中包含更多较弱的长期条件关联。

---

### （2）窗口越长，网络越平滑

平均 Turnover 分别为：

\[
0.1959,\quad0.0878,\quad0.0435.
\]

因此：

\[
\boxed{
Turnover_{126}
>
Turnover_{252}
>
Turnover_{504}.
}
\]

半年窗口的平均 Turnover 约为两年窗口的 4.5 倍。

17 次相邻网络比较中，平均每次 edge-change events 分别约为：

\[
9.59,\quad4.29,\quad2.47.
\]

这表明：

- 短窗口具有更高的时间敏感性；
- 长窗口得到更加平滑、持续的网络结构。

需要注意，相邻窗口的重叠比例也随 \(W\) 增大：

\[
84.1\%,\quad92.1\%,\quad96.0\%.
\]

因此，Turnover 随 \(W\) 增大而下降不仅反映时间尺度差异，也包含更高窗口重叠率带来的机械平滑效应。

---

### （3）Persistence 随窗口长度增大

满足：

\[
Persistence\ge0.8
\]

的边数分别为：

\[
28,\quad39,\quad51.
\]

满足：

\[
Persistence=1
\]

的边数分别为：

\[
20,\quad29,\quad45.
\]

因此：

\[
\boxed{
W\uparrow
\Rightarrow
\text{边的时间持续性总体提高}.
}
\]

---

### （4）同行业边在所有时间尺度下均明显更稳定

同行业边平均 Persistence：

\[
0.944,\quad0.991,\quad1.000.
\]

跨行业边平均 Persistence：

\[
0.305,\quad0.345,\quad0.415.
\]

因此三个窗口尺度下均有：

\[
\boxed{
P_{\mathrm{same}}
\gg
P_{\mathrm{cross}}.
}
\]

满足 \(Persistence\ge0.8\) 的比例分别为：

| Window | Same-industry | Cross-industry |
|---|---:|---:|
| \(W=126\) | 89.47% | 12.79% |
| \(W=252\) | 100% | 23.26% |
| \(W=504\) | 100% | 37.21% |

该结果表明，“行业内部关系更稳定”并不依赖于单一 Window Size。

---

### （5）网络动态变化主要发生在跨行业关系

三个时间尺度下，跨行业边占全部 edge-change events 的比例分别为：

\[
89.57\%,\quad93.15\%,\quad100\%.
\]

因此：

\[
\boxed{
\text{动态支持集变化主要发生在Cross-industry edges}.
}
\]

---

# 四、阶段三：Multi-scale Persistence——识别真正跨尺度的核心边

## 4.1 核心定义

对每条股票边 \((i,j)\)，分别计算：

\[
P_{ij}^{126},
\quad
P_{ij}^{252},
\quad
P_{ij}^{504}.
\]

定义最差尺度持续性：

\[
P_{ij}^{\min}
=
\min
\left\{
P_{ij}^{126},
P_{ij}^{252},
P_{ij}^{504}
\right\}.
\]

若：

\[
P_{ij}^{\min}\ge0.8,
\]

定义为：

\[
\boxed{\text{Multi-scale Persistent Edge}}.
\]

若进一步满足：

\[
P_{ij}^{126}
=
P_{ij}^{252}
=
P_{ij}^{504}
=
1,
\]

定义为：

\[
\boxed{\text{Multi-scale Always-Persistent Edge}}.
\]

---

\[
\boxed{20}
\]

\[
P=1.
\]

因此：

\[
\boxed{

}

中包含：

\[
\boxed{

# 五、阶段四：Edge Lifecycle——区分“阶段性”与“频繁跳动”

## 5.1 研究动机

Persistence 只回答：

\[
\boxed{\text{一条边出现多少次？}}
\]

但不能回答：

\[
\boxed{\text{这些出现是如何沿时间组织的？}}
\]

例如两个 Persistence 相同的股票对：

- 一条可能只在某一连续阶段长期存在；
- 另一条可能频繁进入和退出网络。

因此进一步引入 Edge Lifecycle。

---

## 5.2 主要生命周期指标

针对每条股票边计算：

- `Persistence`；
- `First Selected Date`；
- `Last Selected Date`；
- `Number of Episodes`；
- `Longest Consecutive Run`；
- `Longest Run Share`；
- `Switch Count`；
- `Entry Count`；
- `Exit Count`；
- `Transition Rate`；
- 被选择时的平均 Partial Correlation；
- `Selection Sequence`。

其中 Episode 定义为一段连续的 `selected=1`。

---

## 5.3 描述性生命周期分类

### Persistent Core

\[
Persistence\ge0.8.
\]

表示绝大多数时间窗口中均存在的长期条件关联。

---

### Regime-dependent Edge

满足：

\[
Persistence<0.8,
\]

\[
N_{\mathrm{selected}}\ge3,
\]

且：

\[
N_{\mathrm{episodes}}=1.
\]

表示关系并非长期全局持续，但集中存在于某一个连续时期。

---

### Two-episode Transitional Edge

满足：

\[
Persistence<0.8,
\quad
N_{\mathrm{selected}}\ge3,
\quad
N_{\mathrm{episodes}}=2.
\]

表示存在两个独立出现时期，需要进一步判断是否属于两个阶段性 regime。

---

### Intermittent Edge

满足：

\[
Persistence<0.8,
\quad
N_{\mathrm{episodes}}\ge3.
\]

表示关系反复进入和退出网络，具有较明显的 support switching。

---

### Rare Edge

满足：

\[
N_{\mathrm{selected}}\le2.
\]

表示极少被选择的关系，目前不宜赋予过强经济解释。

---

# 六、阶段五：Dynamic Centrality Stability——节点角色稳定性

## 6.1 研究目的

前几阶段主要分析“边”。

本阶段将研究对象转向股票节点，回答：

\[
\boxed{
\text{哪些股票长期处于网络核心位置，哪些股票只在某些阶段变得重要？}
}
\]

因此，不仅考虑 Degree 和 Strength 的平均水平，还研究节点中心性在时间上的稳定程度。

---

## 6.2 核心指标

对每只股票计算：

### Degree

\[
d_i(t)
=
\sum_{j\neq i}
I\{(i,j)\in E_t\}.
\]

### Strength

\[
s_i(t)
=
\sum_{j:(i,j)\in E_t}
|\rho_{ij,t}^{GL}|.
\]

进一步计算：

- Mean；
- SD；
- CV；
- Min / Max / Range；
- Degree Rank；
- Strength Rank；
- Mean Rank；
- SD Rank；
- Top-central Share。

---

## 6.3 为什么使用 Rank Stability

仅使用 Degree/Strength 可能受到整个网络密度共同变化的影响。

例如：

\[
Degree_i:
10\rightarrow7
\]

不一定意味着节点角色下降。

如果其排名：

\[
Rank_i:
2\rightarrow2,
\]

则说明它仍然长期处于相对核心位置。

因此，对于“节点角色稳定性”，本阶段更强调：

\[
\boxed{
MeanRank + SDRank.
}
\]

---

## 6.4 四种动态节点角色

使用：

\[
MeanRank
\]

判断 Central / Peripheral，

使用：

\[
SDRank
\]

判断 Stable / Dynamic。

对于当前 15 只股票，定义：

\[
MeanRank\le5
\]

为 Central。

稳定性阈值采用股票池横截面：

\[
Median_i\{SDRank_i\}.
\]

因此：

\[
\boxed{
\begin{aligned}
Stable\ Central:\quad&
MeanRank\le5,\quad SDRank\le Median(SDRank);
\\
Dynamic\ Central:\quad&
MeanRank\le5,\quad SDRank>Median(SDRank);
\\
Stable\ Peripheral:\quad&
MeanRank>5,\quad SDRank\le Median(SDRank);
\\
Dynamic\ Peripheral:\quad&
MeanRank>5,\quad SDRank>Median(SDRank).
\end{aligned}
}
\]

这是描述性节点角色分类规则，而非唯一理论标准。

---

## 6.5 Stage 5 主文件

```text
dynamic_centrality_stability.csv
```

作为节点级 Master Table。

其中建议明确记录：

- `mean_degree_rank`
- `sd_degree_rank`
- `degree_rank_sd_threshold`
- `degree_central`
- `degree_rank_stable`
- `mean_strength_rank`
- `sd_strength_rank`
- `strength_rank_sd_threshold`
- `strength_central`
- `strength_rank_stable`
- `degree_role`
- `strength_role`
- `combined_role`

以保证分类过程透明、可复现。

# 十二、今日形成的核心研究结论

## 12.1 第一层：网络动态程度具有明显时间尺度依赖性

\[
\boxed{
W\uparrow
\Rightarrow
\text{网络更稠密、更平滑、Persistence更高、Turnover更低}.
}
\]

因此动态网络的具体拓扑并不存在一个完全与 Window Size 无关的唯一描述。

---

## 12.2 第二层：行业结构排序具有明显跨尺度稳健性

尽管整个网络的稠密度和动态程度依赖 Window Size，但三个尺度均有：

\[
\boxed{
Persistence_{\mathrm{same}}
\gg
Persistence_{\mathrm{cross}}.
}
\]

说明：

\[
\boxed{
\text{同行业关系更加稳定}
}
\]

这一结构性排序具有较强 Window-size Robustness。

---

## 12.3 第三层：真正跨尺度核心明显集中于同行业关系

同行业候选边成为 Multi-scale Core 的比例：

\[
89.47\%.
\]

跨行业仅为：

\[
12.79\%.
\]

这进一步支持：

\[
\boxed{
\text{Stable Industry Core}.
}
\]

---

## 12.4 第四层：跨行业关系承担主要动态变化

无论是：

- Raw edge changes；
- 标准化 State-change Rate；
- Exit Rate；

均显示跨行业关系明显更加动态。

因此：

\[
\boxed{
\text{Dynamic Cross-industry Periphery}
}
\]

不是单纯由跨行业候选边数量更多所造成。

---

## 12.5 第五层：跨行业动态主要是“阶段依赖”，而非“频繁随机跳动”

Lifecycle 结果显示，跨行业非核心关系主要集中于：

- Regime-dependent；
- Two-episode Transitional；

真正 Intermittent 边数量较少。

因此最终更精确的结构性结论为：

\[
\boxed{
\textbf{Stable Industry Core}
+
\textbf{Regime-sensitive and Temporally Heterogeneous Cross-industry Periphery}
}
\]

即：

> **相对稳定的行业内部核心 + 更具阶段依赖性和时间异质性的跨行业动态外围。**

# 十五、需要保留的方法解释与限制

1. Graphical Lasso 识别的是**条件关联结构**，不能解释为因果关系；
2. Persistence、Lifecycle、State-change Rate 等均为描述性动态网络指标；
3. Rolling Windows 高度重叠，因此相邻网络不能视为独立样本；
4. Window Size 增大时，Turnover 下降部分来自窗口重叠率提高产生的机械平滑；
5. \(P\ge0.8\) 以及 Lifecycle 分类阈值属于工作性的描述性定义，不是金融网络理论中的唯一标准；
6. Lifecycle 中的 network date 是 trailing rolling window 的结束日期，不应直接视为真实经济事件的精确发生时间；
7. “Stable Industry Core + Dynamic Cross-industry Periphery”目前应表述为多指标、多尺度下的一致描述性证据，而非严格统计或因果证明。

# 十六、今日工作成果总结

今日工作在已有 Rolling Graphical Lasso 动态网络基础上，完成了从“单一时间尺度下观察动态网络”向“多时间尺度、边生命周期、节点角色及行业结构综合验证”的进一步推进。

核心成果包括：

- 验证动态网络的具体稠密度和 Turnover 对 Window Size 存在明显依赖；
- 识别出 28 条真正跨尺度持续核心边，其中 20 条在三个 Window Size 下始终存在；
- 前期 9 条最强关系全部进一步通过跨 Window Size 稳健性检验；
- 建立 Edge Lifecycle 框架，将低 Persistence 边进一步区分为阶段性、两阶段、间歇性和稀有关系；
- 建立 Dynamic Centrality Stability 框架，从 Degree/Strength 及其排名稳定性角度刻画股票节点的动态角色；
- 通过 Persistence、Multi-scale Core、State-change Rate、Exit Rate 和 Lifecycle 等多项指标综合验证了行业内部关系更加稳定、跨行业关系更加动态的结构；
- 将最终结构性发现进一步精炼为：

\[
\boxed{
\textbf{Stable Industry Core}
+
\textbf{Regime-sensitive and Temporally Heterogeneous Cross-industry Periphery}
}
\]

即：

> **行业内部关系形成相对稳定的长期核心，而跨行业关系构成更具阶段依赖性和时间异质性的动态外围。**

该结论为后续进一步研究市场状态、行业轮动、结构变化时期以及更高级动态精度矩阵模型提供了较为清晰的实证基础。
