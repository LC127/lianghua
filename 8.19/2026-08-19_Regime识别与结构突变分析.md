## 二、Stage 1：建立 Dynamic Network State Table

### 2.1 研究目标

将已有的 Rolling Graphical Lasso edge-level 结果

\[
G_1,G_2,\ldots,G_{31}
\]

转换为 network-level 时间序列，使每一个 network date 对应一个网络状态观测。核心目标是构建：

\[
\boxed{X_t=(EdgeCount_t,Density_t,Mean|\rho|_t,SameEdges_t,CrossEdges_t,Turnover_t,\ldots)}
\]

从而为后续高变化时期识别和 Regime Detection 提供统一输入。

### 2.2 主要网络状态指标

- **Edge Count**：
  \[
  E_t=|E(G_t)|.
  \]
- **Density**：15 只股票共有 \(\binom{15}{2}=105\) 个候选股票对，因此
  \[
  Density_t=E_t/105.
  \]
- **Mean Absolute Partial Correlation**：
  \[
  \overline{|\rho|}_t=\frac{1}{|E_t|}\sum_{(i,j)\in E_t}|\rho_{ij,t}^{GL}|.
  \]
- **Same-industry / Cross-industry Edges**：
  \[
  E_t^{same}=\#\{(i,j)\in E_t:Industry_i=Industry_j\},
  \]
  \[
  E_t^{cross}=\#\{(i,j)\in E_t:Industry_i\neq Industry_j\}.
  \]
- **Same-industry Ratio**：
  \[
  SameRatio_t=E_t^{same}/E_t.
  \]

### 2.3 相邻网络转换指标

定义 Jaccard Similarity：

\[
J_t=\frac{|E_{t-1}\cap E_t|}{|E_{t-1}\cup E_t|},
\]

进一步定义：

\[
\boxed{Turnover_t=1-J_t}.
\]

同时计算：

\[
Lost_t=|E_{t-1}\setminus E_t|,
\qquad
Gained_t=|E_t\setminus E_{t-1}|.
\]

Gross Edge Changes 为：

\[
\boxed{GrossChange_t=Lost_t+Gained_t},
\]

用于衡量相邻网络总共发生多少次边状态变化；而 Net Edge Change 为：

\[
\boxed{\Delta E_t=E_t-E_{t-1}=Gained_t-Lost_t},
\]

用于判断网络是在扩张还是收缩。

今日进一步明确：

\[
\boxed{GrossChange_t\neq \Delta E_t}.
\]

例如 Lost=10、Gained=10 时，GrossChange=20，但 \(\Delta E=0\)，代表大量 rewiring，而不是网络规模变化。

## 三、Stage 2：高变化时期识别

### 3.1 研究目标

Stage 2 主要识别：

\[
\boxed{\text{哪些相邻 Rolling Networks 之间的变化明显高于通常水平？}}
\]

该阶段不是正式 Change-point Detection，而是建立透明、易解释的描述性异常筛选框架。

### 3.2 核心指标

- **Turnover**：衡量相对支持集变化程度。
- **Gross Edge Changes**：衡量绝对边状态变化数量。
- **Net Edge Change**：
  \[
  \Delta E_t=Gained_t-Lost_t,
  \]
  用于判断 Expansion / Contraction。
- **Absolute Net Change**：
  \[
  |\Delta E_t|.
  \]
- **Rewiring Share**：
  \[
  \boxed{RewiringShare_t=\frac{2\min(Lost_t,Gained_t)}{Lost_t+Gained_t}}.
  \]
  越接近 1，说明越接近边替换；越接近 0，说明主要是单向扩张或收缩。
- **Cross-industry Change Share**：
  \[
  \boxed{CrossChangeShare_t=\frac{LostCross_t+GainedCross_t}{Lost_t+Gained_t}}.
  \]

### 3.3 Z-score 异常识别

对任意指标 \(X_t\)，计算：

\[
Z_{X,t}=\frac{X_t-\bar X}{s_X}.
\]

重点使用：

\[
Z_t^{Turnover},\qquad Z_t^{Gross}.
\]

描述性筛选规则：

- \(Z\ge1\)：Moderate High-change；
- \(Z\ge1.5\)：Strong High-change；
- \(Z\ge2\)：Very Strong High-change；
- 若 \(Z_t^{Turnover}\ge1\) 且 \(Z_t^{Gross}\ge1\)，定义为 Joint High-change。

同时补充 Robust Z-score：

\[
RZ_t=0.6745\frac{X_t-Median(X)}{MAD(X)},
\]

用于降低少数极端值对均值和标准差的影响。

### 3.4 Change Type 分类

根据 Lost、Gained、\(\Delta E\) 与 RewiringShare，将网络变化划分为：

- Stable Support；
- Expansion-dominant；
- Contraction-dominant；
- Pure Rewiring；
- Rewiring with Expansion；
- Rewiring with Contraction。

这使 Stage 2 不只回答“哪里变化最大”，还回答“变化属于什么类型、主要来自哪里”。

## 四、Stage 3：Structural Change / Regime Detection

### 4.1 研究目标

Stage 2 关注局部网络转换 \(G_{t-1}\rightarrow G_t\)，而 Stage 3 进一步研究：

\[
\boxed{\text{31 张 Rolling Networks 能否划分为若干具有持续性的结构状态？}}
\]

即：

\[
Regime_1\rightarrow Regime_2\rightarrow\cdots\rightarrow Regime_R.
\]

### 4.2 Network State Vector

为避免指标冗余，选取：

\[
\boxed{X_t=(SameEdges_t,CrossEdges_t,Mean|\rho|_t)}.
\]

其中 SameEdges 表示行业内部结构规模，CrossEdges 表示跨行业动态外围规模，Mean \(|\rho|\) 表示被保留条件关联的平均强度。

### 4.3 连续分段方法

将变量标准化：

\[
Z_{tm}=\frac{X_{tm}-\bar X_m}{s_m}.
\]

对任一连续区间 \([s,e]\)，定义段内损失：

\[
C(s,e)=\sum_{t=s}^{e}\|Z_t-\bar Z_{s:e}\|_2^2.
\]

利用 Dynamic Programming 寻找：

\[
\boxed{\min\sum_{r=1}^{R}\sum_{t\in I_r}\|Z_t-\bar Z_r\|_2^2},
\]

并要求每个 Regime 为连续时间段。

随后用 BIC-style criterion 对 Regime 数进行描述性选择：

\[
IC(R)=nd\log\left(\frac{RSS_R}{nd}\right)+k_R\log n.
\]

### 4.4 Regime 数量选择结果

| Regime 数 | RSS | BIC-style |
|---:|---:|---:|
| 1 | 90.000 | 7.253 |
| 2 | 44.228 | -45.084 |
| 3 | 23.452 | -90.346 |
| 4 | 14.721 | -119.919 |
| **5** | **10.260** | **-139.760** |

当前设定下选择：

\[
\boxed{R=5}.
\]

## 六、Stage 4：比较不同 Regime 的网络结构

### 6.1 Regime-specific Persistence

对股票边 \((i,j)\)，定义：

\[
\boxed{P_{ij}^{(r)}=\frac1{K_r}\sum_{t\in R_r}I\{(i,j)\in E_t\}}.
\]

若：

\[
P_{ij}^{(r)}\ge0.8,
\]

定义为 Regime Core Edge。

进一步计算相邻 Regime 的：

\[
\Delta P_{ij}=P_{ij}^{after}-P_{ij}^{before}.
\]

### 6.2 Regime Core Structure

| Regime | Core Edges | Same Core | Cross Core |
|---|---:|---:|---:|
| R1 | 44 | 18 | 26 |
| R2 | 51 | 17 | 34 |
| R3 | 52 | 19 | 33 |
| R4 | 36 | 18 | 18 |
| R5 | 37 | 19 | 18 |

最显著的结构特征为：

\[
\boxed{SameCore:17\sim19}
\]

跨 Regime 基本稳定，而：

\[
\boxed{CrossCore:26\rightarrow34\rightarrow33\rightarrow18\rightarrow18}
\]

存在明显 Regime dependence。

### 6.3 不同 Regime Transition 的结构类型

**R1→R2：Cross-industry Expansion + Rewiring**

\[
Core:44\rightarrow51,
\]

其中 Lost=6、Gained=13，且 13 条 Gained Core 全部为 Cross-industry。Core Jaccard 为 0.6667，说明该阶段存在较明显的跨行业扩张与网络重组。

**R2→R3：Stable Adjustment**

Core Jaccard 为 0.8393，是相邻 Regime 中最高的，整体结构最为接近。

**R3→R4：Cross-industry Core Contraction**

\[
Core:52\rightarrow36,
\]

并且：

\[
\boxed{LostCore=16,\qquad GainedCore=0}.
\]

其中：

\[
LostCross=15,\qquad LostSame=1.
\]

因此：

\[
\frac{15}{16}=\boxed{93.75\%}
\]

的 Lost Core 来自跨行业关系，说明该阶段是高度单向的 Cross-industry Persistent-core Contraction。

**R4→R5：Sparse-state Cross-industry Rewiring**

Core 数量基本不变，但 Lost=5、Gained=6，且绝大多数仍为跨行业关系，说明该阶段主要是稀疏网络内部的跨行业重新配置。

### 6.4 R3→R4 的典型 Persistence 下降关系

Stage 4 识别出多条从 R3 中长期稳定存在、进入 R4 后明显弱化或消失的跨行业关系，例如：

- 泸州老窖–赣锋锂业：\(1\rightarrow0\)；
- 泸州老窖–中国平安：\(1\rightarrow0\)；
- 京东方A–伊利股份：\(1\rightarrow0\)；
- 立讯精密–中国平安：\(1\rightarrow0\)。

这说明 R3→R4 的跨行业结构收缩并非只体现在平均边数，而是反映在 Persistent Relationships 的系统性退出上。

## 七、Stage 5：识别 Regime Transition Contributors

### 7.1 研究目标

Stage 4 已回答“哪些边发生变化”，Stage 5 进一步研究：

\[
\boxed{\text{这些变化集中在哪些股票节点周围？}}
\]

这里的 Contributor 为描述性结构变化贡献节点，不代表因果意义上的 Driver。

### 7.2 Regime-specific Node Centrality

对股票 \(i\)，定义平均 Degree：

\[
\bar d_i^{(r)}=\frac1{K_r}\sum_{t\in R_r}d_i(t),
\]

平均 Strength：

\[
\bar s_i^{(r)}=\frac1{K_r}\sum_{t\in R_r}s_i(t),
\]

其中：

\[
s_i(t)=\sum_{j:(i,j)\in E_t}|\rho_{ij,t}^{GL}|.
\]

进一步拆分 Same / Cross Degree 与 Strength，并计算中心性排名变化。

### 7.3 Rank Improvement

定义：

\[
RankImprovement_i=Rank_i^{before}-Rank_i^{after}.
\]

因此：

- 正值：中心性排名提升；
- 负值：中心性排名下降。

### 7.4 Edge-change Burden

定义 Lost Core Edge Burden：

\[
L_i=\sum_{j\neq i}I\{(i,j)\text{ is Lost Core}\},
\]

Gained Core Edge Burden：

\[
G_i=\sum_{j\neq i}I\{(i,j)\text{ is Gained Core}\}.
\]

更重要的是连续型 Persistence Burden：

\[
\boxed{D_i=\sum_{j\neq i}[P_{ij}^{before}-P_{ij}^{after}]_+}
\]

表示 Persistence Drop Burden；

\[
\boxed{U_i=\sum_{j\neq i}[P_{ij}^{after}-P_{ij}^{before}]_+}
\]

表示 Persistence Gain Burden；

\[
\boxed{B_i=\sum_{j\neq i}|\Delta P_{ij}|}
\]

表示 Total Persistence Shift Burden。

进一步定义：

\[
\boxed{Share_i=\frac{B_i}{\sum_k B_k}}
\]

用于衡量节点承担的 endpoint-level 结构变化占比，以及：

\[
\boxed{CrossShiftRatio_i=\frac{B_{i,cross}}{B_i}}
\]

用于判断该节点的变化主要来自同行业还是跨行业关系。

### 7.5 Stage 5 的两类核心排名

- **Edge-structure Contributor Ranking**：以 Persistence Shift Share / Drop Burden 为主要依据，回答“哪些节点周围的关联结构变化最多？”
- **Node-role Shift Ranking**：依据 \(\Delta Degree\)、\(\Delta Strength\)、Degree/Strength Rank Change，回答“哪些股票的相对网络角色变化最大？”

需要强调：

\[
\boxed{\text{Edge Contributor}\neq\text{Role-shift Node}}.
\]

某些股票可能邻接边发生明显变化，但相对中心角色保持稳定；另一些股票可能边结构变化不是最大，但其网络排名发生明显重排。

## 十一、需要保留的方法限制

1. Graphical Lasso 网络表示的是条件关联结构，不能解释为因果关系；
2. High-change Z-score 是描述性异常筛选，不是独立样本下的正式显著性检验；
3. Rolling Windows 高度重叠，因此相邻网络及其衍生指标具有较强序列相关性；
4. Regime Detection 当前采用标准化网络状态向量与连续分段 Dynamic Programming；
5. BIC-style criterion 主要用于描述性 Regime 数量选择，不应过度解释为严格统计推断；
6. Regime 数量及边界可能受到最短 Regime 长度、状态变量选择等设定影响；
7. \(P\ge0.8\) 的 Regime Core 标准为工作性定义，且不同 Regime 长度会带来离散阈值效应；
8. “Transition Contributor”表示结构变化在节点上的集中程度，不代表因果意义上的“某只股票导致 Regime Change”。

## 十二、今日工作成果总结

今日完成了从动态网络描述到结构状态解释的重要推进。首先将 Rolling Graphical Lasso 的 edge-level 结果整理为 network-level Dynamic State Table，并建立 Turnover、Gross Change、Net Edge Change、Rewiring Share 和 Cross-industry Change Share 等指标，用于识别高变化时期。

随后构建由同行业边数、跨行业边数和平均绝对偏相关组成的多变量 Network State Vector，并利用连续分段 Dynamic Programming 进行 Structural Change / Regime Detection。当前结果识别出五个描述性 Network Regimes，其中 2025-10-16 至 2025-11-13 附近的 R3→R4 是最值得关注的结构转换之一：网络由高密度状态转入明显稀疏状态，而同行业关系基本保持稳定，跨行业关系发生大幅收缩。

在 Regime Network Comparison 中，进一步发现同行业 Core Edge 数在五个 Regimes 中始终维持在 17–19 条，而跨行业 Core Edge 数发生明显状态变化。R1→R2 主要体现跨行业持续性关系扩张与重新配置，R3→R4 则表现为高度单向的跨行业 Persistent Core 收缩，其中 16 条 Lost Core 中有 15 条为跨行业关系。

最后，进一步建立节点级 Regime Transition Contributor 分析框架，通过 Degree、Strength、Rank、Lost/Gained Core Burden、Persistence Drop/Gain Burden、Persistence Shift Share 和 Cross Shift Ratio 等指标，研究 Regime 结构变化集中在哪些股票周围，以及这些边结构变化是否进一步改变股票在网络中的相对中心角色。

总体而言，今日工作使此前得到的：

\[
\boxed{\text{Stable Industry Core}+\text{Regime-sensitive Cross-industry Periphery}}
\]

得到了 Network State、Regime、Edge 和 Node 多层次框架的进一步支持与细化，并为后续研究不同 Regime 的经济含义、市场状态对应关系和更高级动态网络模型奠定了基础。
