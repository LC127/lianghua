# 二、Stage 1：固定重叠率下的 Window Size 稳健性分析

- \(W=126\)：Overlap \(\approx 84.13\%\)
- \(W=252\)：Overlap \(\approx 92.06\%\)
- \(W=504\)：Overlap \(\approx 96.03\%\)

这会导致 Window Size 和 Rolling Overlap 两个因素混杂。

因此本阶段采用：

- \(W=126,\ STEP=10\)
- \(W=252,\ STEP=20\)
- \(W=504,\ STEP=40\)

使三个设定均满足：

\[
\boxed{
Overlap \approx 92.06\%
}
\]

从而在尽量控制重叠比例的前提下重新比较时间尺度效应。

# 三、Stage 2：构造不依赖 GLasso 稀疏惩罚的动态条件关联基准

## 1. 研究目的

为判断前期发现是否过度依赖 Graphical Lasso 的 \(L_1\) 稀疏惩罚，本阶段构造 Rolling Partial Correlation Network 作为无惩罚基准。

对于每个 \(W=252,\ STEP=20\) 的滚动窗口：

\[
S_t=\text{sample covariance matrix},
\]

\[
\Omega_t=S_t^{-1},
\]

并计算偏相关：

\[
\rho_{ij\mid -ij,t}
=
-\frac{\omega_{ij,t}}
{\sqrt{\omega_{ii,t}\omega_{jj,t}}}.
\]

本阶段不做 \(L_1\) penalty，因此完整 Partial Correlation Matrix 通常是稠密的。

## 2. 分析重点

主要保存全部 105 个股票对的连续偏相关：

\[
\boxed{
|\rho_{ij,t}^{PC}|
}
\]

并记录绝对偏相关排序，为后续 Density Matching 提供基础。

同时检查协方差矩阵：

- 最小特征值；
- 最大特征值；
- Condition Number；
- 数值求逆误差；

以确认无正则精度矩阵估计的数值稳定性。

本阶段的作用是建立：

\[
\boxed{
\text{Unregularized Conditional-association Baseline}
}
\]

而不是直接与 GLasso 的稀疏网络进行不公平比较。

# 四、Stage 3：Density-matched Method Comparison

## 1. 研究目的

普通 Partial Correlation Network 和 GLasso Network 的网络稠密度天然不同，如果直接比较：

- Persistence
- Turnover
- Persistent Core
- Same/Cross Edge Composition

会混入 Density Effect。

因此对每个日期 \(t\)，设 GLasso 有：

\[
m_t=|E_t^{GL}|
\]

条边。

将 Partial Correlation 的 105 个候选边按：

\[
|\rho_{ij,t}^{PC}|
\]

从大到小排序，只保留前 \(m_t\) 条：

\[
\boxed{
|E_t^{PC,\mathrm{match}}|
=
|E_t^{GL}|
}
\]

实现 window-by-window density matching。

## 2. Density Matching 验证

31 个 Rolling Windows 中全部满足：

\[
\boxed{
|E_t^{Partial,matched}|
=
|E_t^{GLasso}|
}
\]

平均网络边数：

\[
\overline{|E_t|}
\approx 50.48.
\]

\[
\boxed{
0.6543
}

\[
\boxed{

说明控制相同 Density 后，两种方法约有三分之二边一致，但仍存在明显方法差异。

因此：

\[
\boxed{
\text{GLasso 的 }L_1\text{ penalty 不仅改变网络密度，也改变具体支持集。}
}
\]

# 七、Stage 6：Network Regime 与可观察市场状态的对应关系

## 1. 研究目的

在确认 R3→R4 具有跨方法结构支持后，本阶段进一步分析：

\[
\boxed{
\text{Network Regime 是否对应可观察的市场状态变化？}
}
\]

基于 15 只股票构造短期市场指标，重点考察：

- 收益方向；
- 波动水平；
- 下行压力；
- 市场广度；
- 横截面分化。

## 2. 主要市场状态指标

### （1）20日累计收益

用于衡量：

\[
\boxed{
\text{最近约一个月市场总体上涨还是下跌}
}
\]

### （2）20日年化波动率

用于衡量：

\[
\boxed{
\text{市场时间序列上的短期波动程度}
}
\]

### （3）20日平均绝对收益

作为波动程度的辅助描述指标。

### （4）负收益日比例

衡量：

\[
\boxed{
\text{近期下跌出现的频率}
}
\]

### （5）Maximum Drawdown

衡量：

\[
\boxed{
\text{近期从局部高点到低点的最大下行幅度}
}
\]

### （6）Market Breadth

定义为每日上涨股票占比的 20 日平均，用于衡量：

\[
\boxed{
\text{上涨是否得到多数股票共同参与}
}
\]

### （7）Cross-sectional Dispersion

定义为每日 15 只股票收益横截面标准差的 20 日平均，用于衡量：

\[
\boxed{
\text{股票之间的收益表现是否更加分化}
}
\]

### （8）20日累计收益横截面 Dispersion

衡量经过 20 个交易日后，不同股票累计表现之间最终拉开的差距。

因此同行业关系总体更稳定、跨行业关系总体更动态这一结构排序具有较强的 Scale Robustness 和 Method Robustness。

## 2. 具体边并非完全稳健

两种方法控制相同 Density 后：

\[

\]

\[
13
\]

条 Full Structural Consensus Core，

其中：

\[

说明行业主导的稳定核心具有较强证据支持。

## 4. R3→R4 是当前最重要的动态结构转换

GLasso、Density-matched Partial 和 Raw Partial 三个层面均表明：

\[
\boxed{

- 收益转弱；

\[
\boxed{
\text{Market Internal Organization}
}
\]

而不仅仅是：

\[
\boxed{
\text{Traditional Market Risk Level}
}
\]

这是今天最有研究意义的认识之一。

\]

中文表述为：

> **股票动态条件关联网络中存在一个以同行业关系为主、对时间尺度和估计方法均具有较高稳定性的持续性核心；与此同时，大量跨行业关系表现出更高的时间动态性以及更明显的参数和估计方法敏感性。该结构并非简单由 Graphical Lasso 稀疏惩罚或窗口重叠机制所驱动。进一步的 Regime 分析表明，最显著的 R3→R4 转换表现为跨行业条件关联收缩和行业内部关系相对增强，并与收益转弱及市场广度下降相对应，但并非传统高波动危机状态。**

# 十三、方法学注意事项

1. 当前所有网络边表示的是：
   \[
   \boxed{\text{conditional association}}
   \]
   不能解释为因果关系。

2. “Core / Periphery” 是基于 Edge Persistence 的描述性结构，并未拟合正式的 core-periphery statistical model。

3. Rolling Windows 高度重叠，因此不同 Network Date 并非独立样本，当前分析以描述性比较和稳健性验证为主，不宜直接使用普通独立样本显著性检验。

4. \(P\ge0.8\) 是工作性 Persistent Edge 阈值，因此连续 Persistence 值应作为主要证据，阈值分类作为辅助解释。

5. Density-matched Partial 主要用于控制网络稠密度，不能将其中 Top-\(m_t\) 边解释为统计显著边。

6. Stage 6 当前使用的市场状态指标来自同一 15 只股票，因此属于：
   \[
   \boxed{\text{Market-state correspondence}}
   \]
   而非真正意义上的独立外部验证。

7. Stage 6 中若要正式称为“等权投资组合收益”，建议先将个股 log return 转换为 simple return 后再进行每日等权组合构造和累计收益计算，以保证定义更加严格。

# 十四、后续可继续推进的方向

后续若继续开展研究，可优先考虑：

1. 对 Stage 6 的等权收益定义进行 simple-return 修正并快速复核主要结论；
2. 引入真正独立的外部市场变量，例如沪深300、上证指数、市场成交额、市场广度等，进一步验证 Network Regime 的经济含义；
3. 对最重要的 \(R_3\to R_4\) 结构转换进行外部事件背景核验，但避免事后强行匹配事件；
4. 若进入正式研究阶段，可针对 Rolling dependence 设计 block bootstrap / dependence-aware permutation 等统计推断方法；
5. 继续区分：
   - 稳健的行业层面结构；
   - 高证据 Consensus Core；
   - 方法敏感的跨行业外围边；
   以形成更清晰的结构分层解释。

# 十五、今日工作总结

今天的核心工作不是继续增加新的网络模型，而是对前期主要发现进行系统验证。通过控制窗口重叠、构造无惩罚 Partial Correlation 基准、进行等密度方法比较、综合结构稳健性、跨方法验证 Regime，并进一步引入收益、波动、市场广度和横截面分化等市场状态指标，逐步确认：

\[
\boxed{
\text{行业层面的“稳定核心—动态外围”结构具有较强稳健性，}
}
\]

而：

\[
\boxed{
\text{具体边和外围结构则具有明显的方法、尺度和时间敏感性。}
}
\]

同时，最重要的 \(R_3\rightarrow R_4\) 转换不仅在网络拓扑层面存在，而且在无惩罚 Partial Correlation 中表现为跨行业关联收缩和行业集中度提高，并对应于收益转弱和市场广度下降，但并不对应传统意义上的高波动危机状态。

因此，当前动态股票关联网络更可能在传统收益和波动指标之外，进一步捕捉股票市场内部关系结构和组织方式的变化。
