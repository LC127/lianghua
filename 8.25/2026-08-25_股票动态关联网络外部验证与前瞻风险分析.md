# 二、Stage 1：构建外部市场指数数据

## 1. 研究目的

此前市场状态分析主要基于研究样本中的15只股票，因此 Network Structure 与 Market State 使用的是同一股票池。

为进一步检验前期识别出的 Network Regime 是否具有更广泛的市场经济含义，今天引入了独立外部市场基准：

- 沪深300（CSI300）
- 中证500（CSI500）
- 上证综指（SSE）

主要作用是从更广泛的市场层面验证：

\[
\boxed{
R_1,\ldots,R_5
\text{ 是否对应不同的外部市场状态}
}
\]

## 2. 数据情况

最终获得：

- CSI300：882个交易日
- CSI500：882个交易日
- SSE：882个交易日

时间范围：

\[
2023\text{-}01\text{-}03
\rightarrow
2026\text{-}08\text{-}24
\]

数据中主要保留：

- Open
- High
- Low
- Close
- Volume
- Simple Return
- Log Return
- High-Low Range

其中：

\[
R_t=\frac{P_t}{P_{t-1}}-1
\]

以及：

\[
r_t=\log P_t-\log P_{t-1}.
\]

并验证：

\[
R_t=e^{r_t}-1.
\]

## 3. Trading Activity 指标调整

由于当前指数数据中没有有效的 `amount` 字段，因此 Stage 2 不再强行使用成交额，而使用成交量构造相对交易活跃度：

\[
\boxed{
VolumeActivity_{20/60,t}
=
\frac{
\overline{Volume}_{20,t}
}{
\overline{Volume}_{60,t}
}
-1
}
\]

其中：

- \(>0\)：近期成交量高于中期平均水平；
- \(<0\)：近期成交量低于中期平均水平。

因此 Stage 1 当前数据已经足够支撑后续研究，无需额外扩充大量指标。

## 5. R2：高波动 Active Repricing State

R2 在三个外部指数中都表现出明显较高的波动率：

\[
CSI300:23.53\%
\]

\[
CSI500:29.61\%
\]

\[
SSE:20.96\%
\]

同时成交活跃度均明显高于其他 Regime。

但 R2 的收益并不低，反而整体为正，因此不适合解释为简单危机状态。

更合理的描述为：

\[
\boxed{
\text{High-volatility Active Repricing State}
}
\]

同时注意到 R2 的部分均值受到少数高收益、高波动窗口影响，因此需要结合 Median 一起解释。

---

## 6. R3：Stable Dense + Calm Positive State

R3 在三个指数中都表现为：

- 正收益；
- 较低波动；
- 较低 Negative Day Share；

因此与此前网络中的“稳定稠密”结构高度一致。

可描述为：

\[
\boxed{
\text{Stable Dense Network + Relatively Calm Positive Market State}
}
\]

---

## 7. R3→R4：不属于统一的 Broad-market Deterioration

此前基于15只股票内部市场指标时，R3→R4 一度被解释为弱市场状态。

但外部指数显示：

- CSI300 收益下降；
- CSI500 收益提高；
- SSE 基本稳定；
- 波动率并无统一上升；
- Drawdown 也未统一恶化。

因此：

\[
\boxed{
R_3\rightarrow R_4
\text{并没有表现出统一的广义市场恶化。}
}
\]

R4 更适合描述为：

\[
\boxed{
\text{Industry-concentrated Network Structural Regime}
}
\]

而不是直接定义为 Weak-market Regime。

---

## 8. R4→R5：真正具有一致的市场弱化特征

R4→R5 中：

- CSI300、CSI500、SSE 收益全部下降；
- 三个指数波动率全部上升；
- 最大回撤全部恶化；
- Negative Day Share 全部增加。

因此：

\[
\boxed{
R_4\rightarrow R_5
}
\]

比 R3→R4 更接近：

\[
\boxed{
\text{Broad-market deterioration transition}
}
\]

R5 可以描述为：

\[
\boxed{
\text{Sparse Network + Weak and Higher-risk Market State}
}
\]

# 六、Stage 5：增量 Walk-forward 预测检验

## 1. 研究目的

检验 Stage 4 中发现的 forward association 是否能够转化为实际预测增益。

预测目标：

\[
\boxed{
FutureRelativeVolatility_t
=
FutureVol_{CSI500,t}
-
FutureVol_{CSI300,t}
}
\]

Baseline：

\[
FutureRelVol_t
=
\alpha
+
\beta CurrentRelVol_t
+
\varepsilon_t.
\]

Network-Augmented：

\[
FutureRelVol_t
=
\alpha
+
\beta_1CurrentRelVol_t
+
\beta_2SameEdgeRatio_t
+
\varepsilon_t.
\]

同时使用 Edge Count 作为敏感性检验。

采用：

\[
\boxed{
\text{Expanding-window Walk-forward}
}
\]

进行伪样本外预测。

Initial Train Size 主设定为：

\[
15
\]

并对：

\[
12,\ 15,\ 18
\]

进行敏感性检查。

---

## 2. 主预测结果

| Model | MAE | RMSE | MAE Improvement | RMSE Improvement | Relative OOS \(R^2\) |
|---|---:|---:|---:|---:|---:|
| Baseline | 0.03515 | 0.04150 | — | — | 0 |
| + Same Edge Ratio | 0.03655 | 0.05297 | -3.97% | -27.65% | -0.630 |
| + Edge Count | 0.04141 | 0.05677 | -17.80% | -36.81% | -0.872 |

因此：

\[
\boxed{
\text{加入 Network Feature 后总体预测误差并未改善。}
}
\]

尤其：

\[
R^2_{OOS,rel}<0
\]

说明 Network-Augmented Model 的总体平方预测误差高于 Baseline。

---

## 3. 但 Same Edge Ratio 并非完全没有信息

虽然整体 RMSE 更差，但：

- Same Ratio Model 在 16 个 OOS 预测中约有 9 个时期绝对误差小于 Baseline；
- Median Absolute Error 也低于 Baseline；
- Prediction–Actual Spearman 从 Baseline 的负值改善为正值。

因此：

\[
\boxed{
\text{Network Feature可能包含一定排序或状态信息，
但当前线性模型Calibration不稳定。}
}
\]

\\[4pt]
\downarrow\\
\text{Dependence Organization Shift}\\
CrossIndustryAssociation\downarrow
\\[4pt]
\downarrow\\
\text{Predictive Mapping Shift}\\
\text{Historical Network–Risk relation loses calibration}
\end{array}
}
\]

因此：

\[
R_3\rightarrow R_4
\]

不仅是网络结构上的变化，也表现为网络特征分布相对于此前训练历史发生显著偏移。

但当前尚未进行正式 statistical change-point inference，因此更适合称为：

\[
\boxed{
\text{distributional / structural shift}
}
\]

而非正式统计意义上的 change point。

# 九、今日最重要的综合结论

今天的研究得到以下五点主要认识。

## 1. 不同 Network Regime 的确对应不同的外部市场状态

R2、R3、R5 尤其表现出相对明确的外部市场特征。

其中：

\[
R_2
\]

更接近高波动 Active Repricing State；

\[
R_3
\]

更接近平稳正收益状态；

\[
R_5
\]

更接近弱收益、高风险市场状态。

---

## 2. R3→R4 不是简单 Broad-market Deterioration

外部 CSI300、CSI500 和 SSE 对 R3→R4 没有给出统一的市场恶化信号。

因此 R4 更适合解释为：

\[
\boxed{
\text{Industry-concentrated Network Structural Regime}
}
\]

而非传统高波动危机状态。

---

## 3. R3→R4 也不是立即发生的 Size Rotation

局部 Event-window 进一步显示，CSI500 相对 CSI300 的显著走强发生在 R4 后期，而不是 Network Break 当时。

所以：

\[
\boxed{
\text{Network transition precedes delayed relative market differentiation}
}
\]

只能作为描述性时间顺序，而不能解释为因果或预测关系。

---

## 4. Network Structure 与未来 Risk 的关系强于未来 Return

Stage 4 发现：

\[
\boxed{
SameEdgeRatio\uparrow
\Rightarrow
FutureRelativeVolatility\uparrow
}
\]

以及：

\[
\boxed{
EdgeCount\downarrow
\Rightarrow
FutureRelativeVolatility\uparrow.
}
\]

但：

\[
SameEdgeRatio
\]

与 Future Relative Return 几乎没有稳定关系。

因此网络更像：

\[
\boxed{
\text{Future Risk-state Indicator}
}
\]

而不是未来收益信号。

---

## 5. Forward Association 尚不能转化为稳定样本外预测能力

Stage 5 的 Walk-forward 结果表明：

\[
RMSE_{Network}>RMSE_{Baseline},
\]

且：

\[
R^2_{OOS,rel}<0.
\]

Network Model 在普通时期可能具有一定排序信息，但在 R3→R4 这种新的网络状态下发生明显线性外推失败。

因此：

\[
\boxed{
\text{Network Industry Concentration contains forward-looking risk information,
but does not yet provide robust incremental forecast accuracy.}
}
\]

# 十、方法学注意事项

1. 当前所有网络关系均属于：
   \[
   \boxed{\text{conditional association}}
   \]
   不能解释为因果关系。

2. CSI300、CSI500、SSE 用于外部市场对应验证，但它们仍属于同一 A 股市场，因此不能理解为完全独立样本验证。

3. Stage 3 的 Event Window 属于描述性局部分析，不是正式 event study，也不能把首个 R4 日期解释为精确经济事件发生日。

4. Stage 4 的 Spearman 结果表示 forward association，不等于 predictive ability。

5. Stage 5 的 Walk-forward 属于 pseudo-out-of-sample robustness check，因为 Same Edge Ratio 的选择已经参考了 Stage 4 全样本结果。

6. 当前只有31个 Network Dates，因此不适合继续使用复杂机器学习模型来追求更高拟合或预测表现。

7. Network Features 本身具有较高的 serial dependence，应避免把31个 Network Dates 视为完全独立样本。

8. Stage 5 中网络模型的预测失败主要发生在新的 Network Regime 中，因此后续若扩展研究，应重点关注：
   \[
   \boxed{\text{Regime-dependent Network–Risk Mapping}}
   \]
   而不是简单增加模型复杂度。

---

# 十一、今天工作后的研究结构更新

目前整个股票动态关联网络研究可以概括为：

\[
\boxed{
\begin{array}{c}
\text{Stable Industry Core}\\
+\\
\text{Dynamic / Setting-sensitive Cross-industry Periphery}
\\[4pt]
\downarrow\\
\text{Network Regimes}
\\[4pt]
\downarrow\\
\text{External Market Correspondence}
\\[4pt]
\downarrow\\
\text{Forward Relative-risk Association}
\\[4pt]
\downarrow\\
\text{Regime-sensitive Forecast Calibration}
\end{array}
}
\]

当前最成熟的研究结论已经不再只是：

\[
\text{“同行业边更稳定，跨行业边更动态”}
\]

而进一步扩展为：

> **股票动态条件关联网络中存在以同行业关系为主的稳定核心以及更具时间异质性和设定敏感性的跨行业外围。该行业层面的结构排序在多时间尺度和不同条件关联估计方法下均具有较强稳健性。进一步的 Regime 分析表明，网络结构状态并非传统收益或波动状态的简单复制，其中 R3→R4 表现出明显的网络稀疏化与行业集中化，但未对应统一的广义市场冲击。当前网络行业集中度与随后 CSI500 相对于 CSI300 的风险分化存在一定 forward association，但这种关系在新的网络状态出现时具有明显的 Calibration Shift，因此尚不能转化为稳健的增量样本外预测能力。**

# 十二、后续可继续研究的方向

如果后续继续推进，建议优先考虑：

1. 将预测失败视为研究对象，进一步分析：
   \[
   \boxed{\text{Network–Risk Mapping 是否存在 Regime Dependence}}
   \]

2. 在更长历史时期构建更多 Network Dates，增加真正可用于预测验证的样本量。

3. 在样本量扩大后，再考虑：
   - threshold / spline regression；
   - regime-specific regression；
   - time-varying coefficient model；
   而不是当前直接使用复杂机器学习。

4. 引入更广泛的外部市场状态变量，例如：
   - 沪深300/中证500成交额；
   - 市场整体 Breadth；
   - 风格指数；
   - 行业指数；
   进一步解释 Network Regime 的经济含义。

5. 如果未来要进入真正量化信号研究，应使用：
   \[
   \boxed{\text{completely untouched test period}}
   \]
   或 nested walk-forward，避免特征选择与最终预测检验使用同一完整样本。

# 十三、今日工作总结

第十一天的核心工作完成了从“网络内部结构分析”向“外部经济验证与前瞻风险检验”的重要推进。

今天首先通过 CSI300、CSI500 和 SSE 对此前识别的 Network Regime 进行了外部市场验证，确认不同 Regime 确实对应不同市场状态，但这种对应并非简单的一一映射。随后针对最重要的 R3→R4 进行了局部事件窗口分析，发现网络行业集中化发生在前，而 CSI500 相对于 CSI300 的显著相对走强主要出现在更晚阶段，因此不能简单将 R4 解释为即时风格轮动。

进一步使用全部31个 Network Dates 构造严格的当前网络特征—未来20日市场结果数据集后，发现网络结构与未来收益方向的关系较弱，但与未来相对市场风险存在更明显的 forward association。尤其是 Same-industry Edge Ratio 越高、Edge Count 越低，随后 CSI500 相对于 CSI300 的波动率差越大。

最后通过 expanding-window walk-forward 检验发现，这种 forward association 尚不能稳定转化为增量样本外预测优势。预测误差主要集中于 R3→R4 后的新网络状态，说明历史 Network–Risk 映射关系在结构转换后出现明显 Calibration Shift。

因此，今天最重要的量化研究认识可以概括为：

\[
\boxed{
\text{Association}
\neq
\text{Forward Association}
\neq
\text{Stable Forecastability}.
}
\]

当前股票动态关联网络更适合作为理解市场内部结构、风险分化以及状态变化的工具，而其是否能够形成稳定可交易的预测信号，仍需要更长时间序列、更严格的样本外设计和对 Regime-dependent 关系的进一步研究。
