# 二、Stage 1：Network Distribution Shift Quantification

## 1. 研究目的

第十一天 Stage 5 已经发现，首个 R4 Network Date 的 Same Edge Ratio 和 Edge Count 明显超出此前训练分布。

因此 Stage 1 的目标是把这一单点诊断推广到全部 Network Dates，并建立一套严格遵守时间顺序的实时 Network OOD 衡量体系。

对于每个日期 \(t\)，只使用：

\[
1,\ldots,t-1
\]

的历史 Network States 计算当前状态相对于历史的偏离程度。

主要研究特征为：

\[
\boxed{
EdgeCount_t
}
\]

\[
\boxed{
SameEdgeRatio_t
}
\]

\[
\boxed{
SameCrossStrengthRatio_t
}
\]

并将 Mean Absolute Partial 作为辅助指标。

---

## 2. 构造的 Distribution Shift 指标

### Expanding Z-score

\[
\boxed{
Z_t
=
\frac{
X_t-\bar X_{1:t-1}
}{
S_{1:t-1}
}
}
\]

用于度量当前 Network Feature 偏离历史均值多少个标准差。

---

### Robust Z-score

\[
\boxed{
Z_t^{robust}
=
\frac{
X_t-\operatorname{Median}(X_{1:t-1})
}{
1.4826\times MAD(X_{1:t-1})
}
}
\]

用于降低历史极端值对均值和标准差的影响。

---

### Historical Percentile

\[
\boxed{
Percentile_t
=
\frac{
\sum_{s<t}I(X_s\le X_t)
}{
t-1
}
}
\]

用于判断当前值处于历史分布中的相对位置。

---

### Historical Range Break

\[
\boxed{
RangeBreak_t
=
I
\left(
X_t<\min_{s<t}X_s
\text{ or }
X_t>\max_{s<t}X_s
\right)
}
\]

用于识别当前 Network State 是否超出此前历史支持范围。

---

### Support Excursion

进一步计算当前值超出历史 Min–Max 范围的标准化距离，用于区分“轻微创历史新高/新低”和“远离历史支持区域”的情况。

---

### Joint OOD Score

定义：

\[
\boxed{
JointOOD_t
=
\max_j |Z_{j,t}|
}
\]

其中 \(j\) 包括：

- Edge Count；
- Same Edge Ratio；
- Same/Cross Strength Ratio。

同时记录：

\[
\boxed{
NRangeBreak_t
}
\]

表示有多少个核心 Network Features 同时突破历史支持范围。

当前可以用下面的链条描述：

也就是说：

> 一个 Network Feature 即使在历史样本中与未来风险存在稳定方向关系，也不能保证这种映射能够在新的 Network Regime 中可靠外推。

# 八、今天最重要的研究结论

## 1. R3→R4 是明显且持续的 Network Distribution Shift

首个 R4 同时出现：

\[
EdgeCount\downarrow,
\]

\[
SameEdgeRatio\uparrow,
\]

\[
SameCrossStrengthRatio\uparrow
\]

且三个核心变量全部突破历史支持范围。

---

## 2. Network–Risk Mapping 的变化具有 Feature-specific 特征

Same Edge Ratio 的风险映射明显弱化；

Edge Count 的 slope 基本稳定；

Same/Cross Strength Ratio 没有形成统一弱化模式。

因此不能笼统地说：

\[
\boxed{
\text{所有 Network–Risk Mapping 都在R4后失效。}
}
\]

---

## 3. Historical Mapping 的迁移能力明显下降

即使部分 slope 看起来仍然稳定，Pre-R4 历史模型对 Post-R4 Future Relative Risk 仍然存在严重系统性高估。

因此：

\[
\boxed{
\text{Calibration / Transportability Failure}
}
\]

比简单 slope drift 更能描述当前现象。

---

## 4. Forecast Failure 主要表现为 Tail Risk，而不是普通时期持续失效

首两个 R4 贡献约：

\[
\boxed{68.5\%}
\]

的 Same Ratio Model 总 SSE。

而 Low / Moderate OOD 时，Network Model 平均并未劣于 Baseline。

因此：

\[
\boxed{
\text{当前主要风险不是普通预测误差，
而是新Regime出现时的Tail Calibration Failure。}
}
\]

---

## 5. OOD 不等于必然失败

后两个 R4 仍属于 Extreme OOD，但模型已经重新优于 Baseline。

因此：

\[
\boxed{
\text{当前真正关键的可能不是 OOD magnitude 本身，
而是 Novelty + Historical Support + Adaptation。}
}
\]

# 九、目前最严谨的整体表述

今天不能宣称：

\[
\boxed{
\text{Distribution Shift causes Forecast Failure}
}
\]

也不能宣称：

\[
\boxed{
\text{Concept Drift 已经被严格证明。}
}
\]

当前最稳妥的总结是：

> **The R3–R4 transition is associated with a pronounced and persistent empirical shift in network-state variables. Historical linear network–risk mappings exhibit reduced transportability and calibration in the shifted state, especially for the same-industry edge ratio. Forecast deterioration is strongly concentrated in the initial extreme-OOD observations associated with the transition, while performance partially recovers after the new network state enters the expanding training history. The evidence therefore points to a threshold-like tail calibration problem under previously unsupported network states rather than a smooth monotonic deterioration with OOD severity.**

中文可概括为：

> **R3→R4 对应了显著且持续的网络状态经验分布漂移。进入这一新状态后，历史线性 Network–Risk 映射的迁移与校准能力明显下降，尤其体现在 Same-industry Edge Ratio 上。预测恶化高度集中于结构转换初期的 Extreme-OOD 日期，而随着新状态逐渐进入 expanding training history，模型表现开始恢复。因此当前证据更支持“历史未覆盖网络状态下的阈值型尾部校准失效”，而不是 OOD 程度增加导致预测性能连续单调恶化。**

# 十二、今日工作总结

第十二天的工作重点从“预测模型是否有效”进一步转向“预测模型为什么在结构转换时失效”。

首先，通过 expanding historical Z-score、robust Z-score、historical percentile、range break 和 Joint OOD Score，系统量化了 Network State 的实时分布漂移，确认 R3→R4 是整个研究样本中最显著、持续的 Network Distribution Shift。

随后，通过 Pre-/Post-R4 Network–Risk Mapping 比较发现，Same-industry Edge Ratio 与未来相对风险之间的历史正向映射在进入 R4 后明显减弱，但 Edge Count 并未表现出相同程度的 slope collapse，因此 Network–Risk Mapping 的失稳具有明显的 feature-specific 特征。同时，由于 Pre/Post 网络特征支持区域高度分离，目前更适合将这一现象理解为强 Covariate Shift 下的历史映射迁移与校准失效，而不能直接认定 Concept Drift 已被证明。

最后，将 Network OOD Score 与第十一天 Walk-forward Forecast Error 按日期对齐后发现，OOD 与 Network Model 自身误差之间存在明显正向关系，但 Network Model 相对于 Baseline 的劣化并不是随着 OOD 平滑增加，而主要集中在首两个 R4 Extreme-OOD 日期。这两个日期贡献了 Same Ratio Model 接近70%的总平方预测误差；随着后续 R4 状态进入 expanding history，模型即使仍处于高 OOD 状态，预测表现也逐渐恢复。

因此，今天最重要的研究认识是：

\[
\boxed{
\textbf{
The main forecasting risk is not ordinary prediction error,
but tail calibration failure when the network enters a previously unseen structural state.
}
}
\]

即：

> **当前动态股票关联网络模型面临的主要问题，并不是普通时期持续预测较差，而是在网络首次进入历史未覆盖的新结构状态时，历史 Network–Risk Mapping 可能发生显著的尾部校准失效。**

这使得整个股票动态关联网络研究从最初的“网络结构识别”，进一步发展到：

\[
\boxed{
\text{Dynamic Network State}
\rightarrow
\text{Distribution Shift}
\rightarrow
\text{Mapping Transportability}
\rightarrow
\text{Forecast Calibration Risk}
}
\]

形成了一条更加完整的量化研究主线。
