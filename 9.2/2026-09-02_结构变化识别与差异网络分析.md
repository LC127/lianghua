## 二、研究背景与核心问题

# 四、Stage 2：独立估计 Regime-specific Graphical Lasso 网络

## 4.1 方法

对每一个 Regime 独立估计 Graphical Lasso：

\[
\hat\Omega_r
=
\arg\min_{\Omega\succ0}
\left[
\operatorname{tr}(S_r\Omega)
-\log\det(\Omega)
+\alpha\sum_{i\neq j}|\omega_{ij}|
\right].
\]

描述性网络继续使用此前 Rolling 分析确定的：

\[
\alpha_{1SE}=0.216910.
\]

为保证不同 Regime 之间的网络可比性，所有阶段使用**同一 penalty**，避免 regime-specific tuning 机械地产生 density differences。

由 precision matrix 得到 partial correlation：

\[
\rho_{ij\mid -ij}
=
-\frac{\omega_{ij}}
{\sqrt{\omega_{ii}\omega_{jj}}}.
\]

## 4.2 主要输出

对 R1–R5 分别生成：

- covariance matrix；
- precision matrix；
- partial correlation matrix；
- selected edge list；
- 网络结构 summary。

# 六、文献方法学习：Zhang et al. (2020)

今日进一步总结并应用了 Zhang, Shen and Wang (2020) 的 **Large Multiple Graphical Model Inference via Bootstrap**。

论文研究多阶段 Gaussian graphical models：

\[
G^{(1)},\ldots,G^{(T)}
\]

并对整体 precision matrices 进行检验：

\[
H_0:
\Omega_1=\cdots=\Omega_T.
\]

其核心思想是：

1. 使用正则化 precision matrix estimation；
2. 构造 penalized-estimator-based likelihood-ratio statistic；
3. 在 \(H_0\) 下对 pooled sample 进行 bootstrap；
4. 重新估计 null/common network 与 alternative/stage-specific networks；
5. 使用 bootstrap sampling distribution 给出 critical value 和 p-value。

该方法为当前研究提供了从：

\[
\text{network estimation}
\]

推进到：

\[
\text{network inference}
\]

的理论框架。

同时明确区分：

- 之前的 bootstrap edge-selection stability：研究某条边是否反复被选中；
- Zhang et al. bootstrap MGGM：研究整体阶段网络差异是否超出 \(H_0\) 下的抽样波动。

# 七、Stage 4：R3 vs R4 Bootstrap Whole-network Equality Test

## 7.1 原假设

正式检验：

\[
H_0:
\Omega_{R3}=\Omega_{R4}
\]

vs.

\[
H_1:
\Omega_{R3}\neq\Omega_{R4}.
\]

使用 Gaussian negative log-likelihood：

\[
\mathcal L(S;\Omega)
=
\operatorname{tr}(S\Omega)
-\log\det(\Omega).
\]

构造：

\[
D
=
\frac{1}{Np^2}
\sum_{t\in\{R3,R4\}}
n_t
\left[
\mathcal L(S_t;\hat\Omega_0)
-
\mathcal L(S_t;\hat\Omega_t)
\right].
\]

其中：

- \(\hat\Omega_0\)：pooled common-network estimator；
- \(\hat\Omega_t\)：stage-specific estimator。

## 7.2 样本与参数

- \(n_{R3}=181\)
- \(n_{R4}=61\)
- \(p=15\)
- \(N=242\)
- Bootstrap \(B=1000\)
- inference penalty：

\[
\alpha
=
\frac{\log p}{\min(n_{R3},n_{R4})}
=
0.044394.
\]

## 7.3 检验结果

得到：

\[
D_{\text{obs}}
=
0.002348
\]

bootstrap 95% critical value：

\[
q_{0.95}^{*}
=
0.003073
\]

bootstrap exceedances：

\[
272/1000
\]

因此：

\[
p_{\text{boot}}
=
0.272.
\]

由于：

\[
D_{\text{obs}}
<
q_{0.95}^{*}
\]

且：

\[
p=0.272>0.05,
\]

所以：

\[
\boxed{
\text{Fail to reject }
H_0:\Omega_{R3}=\Omega_{R4}
}
\]

即在当前推断设定下，没有足够证据认为 R3 与 R4 的整体 precision matrices 存在统计可检测的差异。

## 7.4 诊断结果

R3：

\[
\Delta L_{R3}=0.2441
\]

R4：

\[
\Delta L_{R4}=1.3717.
\]

R4 相对于 common-network model 的拟合改善明显更大，但由于其样本量仅为 61，bootstrap null distribution 同样包含较大的有限样本波动，因此整体检验仍不显著。

# 八、Stage 4R：稳健性分析

为判断 Stage 4 的 non-rejection 是否依赖特定 penalty 或样本长度，进一步进行了两类稳健性分析。

---

## 8.1 Penalty Sensitivity

测试：

\[
\alpha
\in
\{
0.044394,
0.06,
0.08,
0.10,
0.15,
0.216910
\}.
\]

结果：

| \(\alpha\) | \(D_{\rm obs}\) | Critical Value | Bootstrap \(p\) | Reject |
|---:|---:|---:|---:|---|
| 0.044394 | 0.002348 | 0.003073 | 0.272 | No |
| 0.060 | 0.002114 | 0.002873 | 0.278 | No |
| 0.080 | 0.001837 | 0.002563 | 0.301 | No |
| 0.100 | 0.001604 | 0.002385 | 0.381 | No |
| 0.150 | 0.001244 | 0.002032 | 0.487 | No |
| 0.216910 | 0.001147 | 0.001796 | 0.425 | No |

全部设定均满足：

\[
p>0.05.
\]

因此：

\[
\boxed{
\text{whole-network non-rejection 对 penalty choice 较稳健}
}
\]

特别地，即使将 penalty 调整至 Stage 2–3 的：

\[
\alpha_{1SE}=0.216910,
\]

整体检验仍然不显著。

值得注意的是，**网络支持集本身对 penalty 较敏感**：

- 小 penalty 下 R4 network 更密；
- 较大 penalty 下 R4 network 更稀。

因此得到一个重要的方法性结论：

\[
\boxed{
\text{Estimated edge support 对 regularization 敏感，
但 whole-network non-rejection 对 regularization 较稳健。}
}
\]

---

为降低：

181:61

样本量不平衡的影响，使用 R3 最后 61 个交易日与完整 R4 的 61 个交易日比较：

\[
n_{R3}=n_{R4}=61.
\]

保持相同：

\[
\alpha=0.044394.
\]

结果：

=
0.003917,
\]

\[
q_{0.95}^{*}
=
0.005386,
\]

\]

仍然：

\[
\boxed{
\text{Fail to reject }H_0.

\]

因此当前 Stage 4 的 non-rejection 不能主要归因于 R3/R4 样本长度不平衡。

## 8.3 Stage 4R 总结

目前可以较严谨地表述：

> 在所考察的一组 Graphical Lasso penalties 以及 equal-length local R3–R4 comparison 下，whole-network bootstrap equality test 始终未拒绝 \(H_0\)。因此，Stage 4 的 non-rejection 在 regularization level 和 sample-length design 两个维度上具有较好的稳健性。

需要强调：

\[
\boxed{
\text{稳健地“不拒绝相等”}
\neq
\text{证明两张网络完全相等}
}
\]

# 十五、今日核心研究结论

今日研究形成了一个比此前更加完整、更加严格的结论体系。

## 15.1 描述层面

R3→R4 确实存在明显的估计网络结构重组：

- 网络边数减少；
- support turnover 较高；
- 重组主要发生在 Cross-industry relations；
- Same-industry support 更稳定；
- 留存关系的强度也发生明显变化。

## 15.2 推断层面

Bootstrap whole-network equality test：

\[
p=0.272
\]

未拒绝：

\[
H_0:
\Omega_{R3}=\Omega_{R4}.
\]

Penalty sensitivity 与 equal-length comparison 均维持 non-rejection，因此：

\[
\boxed{
\text{目前没有稳健证据支持 R3/R4 整体 precision matrix 存在统计显著差异}
}
\]

## 15.3 差异网络层面

Stage 5 进一步表明：

\[
\boxed{
\text{Cross-industry relations dominate support-set turnover}
}
\]

但：

\[
\boxed{
\text{Same-industry relations remain important in continuous strength adjustment}
}
\]

因此此前：

> Stable Industry Core + Dynamic Cross-industry Periphery

应进一步修正为：

> **同行业边支持集具有较高持久性，而跨行业关系承担了大部分边支持集重构；与此同时，部分存续同行业关系的强度发生了明显调整，因此网络转换同时包含跨行业支持集重构和存续关系强度重定价。**

# 十七、今日形成的主要方法认识

1. **网络估计不同不等于总体网络差异显著。**

   \[
   \hat\Omega_{R3}\neq\hat\Omega_{R4}
   \]

   并不能直接推出：

   \[
   \Omega_{R3}\neq\Omega_{R4}.
   \]

2. **Edge support 对 regularization 的敏感程度可能明显高于 whole-network inference。**

3. **支持集稳定性与权重稳定性是不同概念。**

   同行业边可以具有高 retention，但其偏相关强度仍然发生明显变化。

4. **Net edge count 会低估结构变化。**

   R3→R4 净减少 7 条边，但实际上：

   \[
   16\text{ Lost}+9\text{ Gained}=25
   \]

   次支持集变化。

5. **描述性差异网络与显著差异网络必须严格区分。**

   鉴于 Stage 4R 未拒绝整体 equality，当前 Lost/Gained/Strengthened/Weakened 只能解释为 estimated/descriptive changes。

Driver_i

识别 R3→R4 的主要节点驱动者。

# 二十、今日总结

今日工作完成了从 **Rolling network discovery** 到 **Regime-level independent estimation、whole-network inference、robustness verification 和 descriptive differential decomposition** 的完整研究链条。

最重要的发现是：

\[
\boxed{
\text{R3→R4 在估计网络中表现出明显的结构重组，
但当前 whole-network bootstrap inference 并未给出统计显著差异证据。}
}
\]

进一步的差异网络分析表明，跨行业关系明显主导边支持集的退出与新增，而同行业关系虽然支持集更加稳定，其存续边的强度仍可能发生较大调整。因此，R3→R4 更适合被理解为：

\[
\boxed{
\text{cross-industry support reconfiguration}
+
\text{persistent-link strength repricing}
}
\]

而不是简单的“跨行业关系整体收缩”。

这一结果进一步明确了后续研究的重点：从单纯的网络状态识别，转向**结构变化的来源、稳定性、统计可识别性以及其与风险状态和预测失效之间的联系**。
