# 三、Stage 1：A 股全市场研究股票池定义

## 3.1 核心目标

明确后续研究中“哪些股票属于研究对象”，并建立三层动态股票池：

\[
\mathcal U_t^{raw}
\supseteq
\mathcal U_t^{network}
\supseteq
\mathcal U_t^{trade}.
\]

### Raw Universe

历史时点实际上市的 A 股普通股票：

\[
\mathcal U_t^{raw}
=
\{i: ListDate_i\le t<DelistDate_i\}.
\]

第一版建议以沪深 A 股为主样本，北交所保留为扩展样本或稳健性检验。

### Network Universe

满足网络估计数据要求的股票，例如：

- 历史有效观测足够；
- 非长期停牌；
- 数据质量合格。

### Tradable Universe

用于 Alpha 回测的可交易股票池，在 Network Universe 基础上进一步考虑：

- ST/*ST；
- 停牌；
- 新股；
- 流动性；
- 涨跌停等真实交易约束。

## 3.2 关键研究原则

强调 Point-in-Time 原则：

\[
\boxed{
\text{历史时点只能使用当时已经可获得的信息}
}
\]

包括上市/退市、ST、停牌、行业分类、Barra 暴露等，避免幸存者偏差和前视偏差。

# 四、Stage 2：A 股全市场数据质量检查与可用性验收

## 4.1 核心目标

回答：

\[
\boxed{
\text{“当前公司服务器中的 A 股全市场数据是否足以支撑正式网络研究？”}
}
\]

## 4.2 主要检查内容

需要系统检查：

1. 历史股票主表是否完整；
2. 每日上市/交易股票覆盖是否完整；
3. OHLCV 是否符合逻辑约束；
4. 复权因子和收益率是否可靠；
5. 停牌是否被正确识别；
6. ST/*ST 是否为历史 Point-in-Time；
7. 行业分类是否具有历史版本；
8. Barra 数据是否可用于历史残差化；
9. 市值、成交额、换手率、PE、PB 等字段是否完整；
10. 是否存在极端异常收益；
11. 缺失是由新股、退市、停牌还是数据错误导致；
12. 不同窗口下可进入网络估计的股票数量。

## 4.3 最终判断方式

Stage 2 最终应给出：

- Pass；
- Conditional Pass；
- Fail；

三类数据验收结论，并明确正式主研究的可用样本期。

# 五、Stage 3：A 股全市场数据结构诊断

## 5.1 核心目标

Stage 3 不直接选网络，而是回答：

\[
\boxed{
\text{“A 股全市场数据本身具有什么结构？”}
}
\]

## 5.2 主要诊断问题

### 高维结构

对：

\[
W=60,\ 120,\ 252
\]

计算：

\[
p_t/W.
\]

判断是否属于典型：

\[
p\gg n
\]

场景，以及全维协方差/精度矩阵估计是否可行。

### 原始相关结构

研究：

\[
Corr(r_i,r_j)
\]

的全市场分布。

### Same vs Cross Industry

比较：

\[
|\rho|_{Same}
\quad\text{与}\quad
|\rho|_{Cross}.
\]

判断是否存在明显行业 block structure。

### 谱结构

通过 PCA / eigenvalue 分析判断市场共同因子强度。

### Raw vs Barra Residual

设：

\[
r_{i,t}
=
\alpha_i+\beta_i^\top F_t+\varepsilon_{i,t},
\]

比较：

\[
Corr(r_i,r_j)
\]

与：

\[
Corr(\varepsilon_i,\varepsilon_j).
\]

判断股票关联有多少来自市场、行业和风格共同因子。

### 市值与流动性异质性

检查低流动性和非同步交易是否影响 correlation / lead-lag。

### 时间变化

判断网络是否有必要动态化，以及合理窗口范围。

### 尾部结构

初步判断是否需要在风险方向加入 Tail Dependence Network。

# 六、Stage 4：候选网络比较、验证与正式选型

## 6.1 核心目标

Stage 4 正式解决：

\[
\boxed{
\text{“基于 A 股数据结构，什么网络最适合 M1？”}
}
\]

## 6.2 第一版候选网络

根据 Stage 3 结果，第一版建议优先比较：

### Candidate A：Raw Correlation Network

作为基础共同波动 benchmark。

### Candidate B：Barra-Residual Correlation Network

用于研究去除传统共同风险后的局部关联。

### Candidate C：Block / Hierarchical Sparse Precision Network

如果行业或社区 block structure 明显，则用于条件关联 benchmark。

### Candidate D：Lead-Lag Network

用于信息扩散、邻居动量和溢出 Alpha。

### Candidate E：Tail-Dependence Network

若尾部共振明显，则作为 Risk 方向扩展。

## 6.3 统一评价标准

不能只看方法复杂度或某一个 IC，而应统一比较：

\[
\boxed{
\text{Scalability}
+
\text{Stability}
+
\text{Interpretability}
+
\text{Alpha Utility}
+
\text{Risk Utility}
}
\]

同时需要统一网络密度或 Top-k 规则，保证不同网络结构可公平比较。

## 6.4 对 Rolling Graphical Lasso 的重新定位

此前 Rolling Graphical Lasso 在 15 股票样本中是重要基础方法，但不应自动成为全市场默认方法。

其可能角色包括：

- 全市场主网络；
- 行业内 Block Sparse Precision；
- CSI300/CSI500 等代表性股票池 benchmark；
- 条件关联验证层。

最终应由 Stage 3–4 的全市场数据证据决定。

# 八、Stage 6：网络 Alpha 因子挖掘、检验与回测

## 8.1 核心目标

回答：

\[
\boxed{
\text{“股票网络是否能够产生传统因子之外的新增 Alpha？”}
}
\]

## 8.2 第一版候选 Alpha

包括：

### Degree / Weighted Degree

\[
Strength_{i,t}
=
\sum_j |w_{ij,t}|.
\]

### Same / Cross Industry Connectivity

例如：

\[
CrossShare_{i,t}.
\]

### PageRank / Eigenvector Centrality

### Neighbor Momentum

\[
NM_{i,t}
=
\frac{
\sum_j w_{ij,t}Mom_{j,t}
}{
\sum_j|w_{ij,t}|
}.
\]

### Network Residual

\[
NetResidual_{i,t}
=
r_{i,t}-PeerRet_{i,t}.
\]

### Community-relative Signal

### Lead-Lag Signal

若正式保留有向网络，则研究 leader 对 follower 的信息扩散。

## 8.3 正式评价体系

Stage 6 必须完成：

- IC；
- Rank IC；
- ICIR；
- yearly / rolling IC；
- 行业中性化；

# 九、Stage 7：网络风险因子、风险传导与尾部风险研究

## 9.1 核心目标

回答：

\[
\boxed{
\text{“网络是否包含传统风险模型之外的风险信息？”}
}
\]

研究分为三层：

\[
\text{Market-level Risk}
+
\text{Stock-level Risk}
+
\text{Transmission Risk}.
\]

## 9.2 市场级 Risk

重点指标包括：

- MeanAbsWeight；
- CrossIndustryStrength；
- Centralization；
- Concentration；
- Transition Intensity；
- Structural Novelty。

## 9.3 个股级 Risk

包括：

- Node Strength；
- Cross-industry Bridge Risk；
- Neighbor Distress Exposure；
- Node Transition Driver。

## 9.4 动态风险指标

### Transition Intensity

\[
TI_t
=
\|R_t-R_{t-1}\|_F.
\]

### Structural Novelty

\[
Novelty_t
=
d(R_t,\mathcal H_{t-1}).
\]

两者分别回答：

- 当前相对上一期变化多大；
- 当前相对整个历史有多罕见。

## 9.5 前瞻风险检验

真正要研究：

\[
NetworkRisk_t
\rightarrow
FutureRisk_{t+h}.
\]

未来风险包括：

- Future Volatility；
- Future Drawdown；
- Future Tail Loss；
- Future Crash Risk；
- Individual Stock Future Risk。

## 9.6 与 Barra 和 Benchmark 比较

检验：

\[
\boxed{
\text{Network Risk 是否具有 traditional risk 之外的增量信息}
}
\]

并且要求样本外验证。

## 9.7 与 M4 的衔接

Stage 7 只负责验证 Network Risk 指标是否有效。

如果某些风险指标最终达到 Validated Level，再输送到 M4，用于：

- 尾部风险预警；
- 减仓规则；
- 对冲；
- 风险预算调整。

# 十一、今日最重要的方法论调整

今天形成了以下几个关键认识。

## 11.1 不再默认 Rolling Graphical Lasso

全市场网络方法必须依据：

\[
\text{A 股数据结构}
+
\text{研究目标}
\]

选择，而不是机械放大小样本方案。

## 11.2 先定义“边的含义”，再选模型

不同边代表：

- 同步共同波动；
- 因子调整后的局部关联；
- 条件关联；
- Lead-Lag；
- Tail Dependence。

因此“哪个网络最好”必须先明确研究问题。

## 11.3 Main + Benchmark + Auxiliary

正式研究应至少保留：

\[
\boxed{
\text{Main Network}
+
\text{Benchmark Network}
}
\]

必要时再加入：

- Alpha Auxiliary；
- Risk Auxiliary。

## 11.4 网络方法选择不能只看网络图

必须比较：

- 计算可扩展性；
- 稳定性；
- 经济解释；
- Alpha 效果；
- Risk 效果。

## 11.5 Alpha 与 Risk 必须严格区分

股票层面的：

\[
Factor_{i,t}\rightarrow FutureReturn_{i,t+h}
\]

属于 Alpha。

市场或个股网络结构：

\[
NetworkRisk_t\rightarrow FutureRisk_{t+h}
\]

属于 Risk。

二者可以联动，但不能混为同一结论。

## 11.6 OOS 是正式研究的必要条件

无论 Alpha 还是 Risk，都不能在全部历史样本上反复调参后直接报告最终结果。

必须保留：

- OOS；
- 或 Walk-forward。
