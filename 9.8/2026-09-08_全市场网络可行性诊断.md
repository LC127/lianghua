### 3.2 修正历史证券身份 mismatch

初始 QA 中出现少量 `RAW_ONLY` / `DAILY_ONLY` mismatch，且长期呈系统性持续，而不是随机缺失。

进一步分析表明，这些问题主要集中在极少数历史证券身份或代码变更情形，而非大规模行情缺失。

因此在 Step 2 中加入了 identity reconciliation：

\[
\text{secID exact match}
\rightarrow
\text{exchange + historical ticker one-to-one reconciliation}
\]

仅在一对一唯一映射时自动 reconcile；对于 ambiguous 情况不自动合并。

最终：

- 未发现大规模 ambiguous mapping；
- 仅剩极少数特殊历史证券需要后续人工核验；
- 该问题不影响后续全市场网络研究主线。

### 3.3 修正停牌数据造成的 QA 假阳性

初始 QA 中曾出现约 28 万条非正价格 / OHLC 逻辑异常。

进一步发现这些记录几乎与停牌 stock-day 一一对应，因此并非行情错误，而是停牌时的零值占位。

修正后的规则为：

\[
isOpen_{it}=1
\]

时才检查：

\[
Open>0,\quad High>0,\quad Low>0,\quad Close>0
\]

及：

\[
High\ge \max(Open,Close),\qquad
Low\le \min(Open,Close).
\]

对于：

\[
isOpen_{it}=0
\]

的记录，零价格占位不再判定为 HIGH，而作为停牌诊断信息保留。

最终确认，约：

\[
\boxed{282668}
\]

条记录属于停牌 stock-day，与此前约 28 万条“价格异常”高度一致。

因此可以确认：

\[
\boxed{
\text{此前大规模价格异常主要是停牌编码导致的 QA 假阳性}
}
\]

而不是底层行情数据库存在系统性错误。

## 四、Step 3：收益率定义、`chgPct` 验证与第一版全市场收益面板

### 4.1 收益率口径自动识别

没有直接假设供应商复权因子口径，而是使用真实数据进行两类候选比较。

#### `chgPct` 单位识别

比较：

\[
R^{vendor}=chgPct
\]

和：

\[
R^{vendor}=\frac{chgPct}{100}.
\]

在复权因子不变化的样本上，用普通价格收益作为基准进行比较。

结果表明：

\[
\boxed{chgPct\text{ 已经是 decimal return}}
\]

即：

\[
chgPct=0.01
\]

表示 1% 收益，无需再除以 100。

---

### 4.2 复权价格方向识别

重点使用：

\[
AdjFactor_t\neq AdjFactor_{t-1}
\]

的约：

\[
\boxed{33744}
\]

个 stock-day 区分 multiply / divide 两种候选。

候选一：

\[
P_{it}^{adj}
=
Close_{it}\times AdjFactor_{it}
\]

候选二：

\[
P_{it}^{adj}
=
\frac{Close_{it}}{AdjFactor_{it}}.
\]

结果中，multiply 方案与供应商 `chgPct` 高度一致：

\[
MAE\approx0.000149,\qquad
Corr\approx0.999654
\]

而 divide 方案误差明显更大：

\[
MAE\approx0.105677,\qquad
Corr\approx0.149995.
\]

因此正式冻结：

\[
\boxed{
P_{it}^{adj}
=
Close_{it}\times AdjFactor_{it}
}
\]

### 4.4 正式定义网络收益

主网络收益定义为：

\[
\boxed{
r_{it}^{network}
=
\log
\left(
\frac{
P_{it}^{adj}
}{
P_{i,t-1}^{adj}
}
\right)
}
\]

仅在：

\[
isOpen_{it}=1
\]

且：

\[
isOpen_{i,t-1}=1
\]

时定义。

停牌记录不人为设置收益为 0，而是：

\[
\boxed{
isOpen=0
\Rightarrow
return\_network=NA
}
\]

以避免将“没有交易”误认为“价格稳定”。

同时保留：

\[
return\_last\_trade\_log
\]

用于跨停牌期累计收益及后续稳健性分析。

## 五、Step 4：全市场网络可行性诊断

今天将原规划中的“全市场网络可行性诊断”作为新的 Step 4。

该步骤的目标不是直接选择 Pearson、Graphical Lasso 等最终网络方法，而是先判断：

\[
\boxed{
\text{在不同滚动窗口和数据完整度要求下，全市场网络的实际维数有多大}
}
\]

并回答：

- 有多少股票能够进入网络；
- individual coverage 是否充分；
- pairwise common observations 是否充分；
- \(p/W\) 的高维程度有多大；
- 网络节点集合是否稳定；
- dense candidate edge 数量和计算量有多大。

---

### 5.1 参数设置

滚动窗口：

\[
W\in\{60,120,252\}
\]

分别约对应：

- 3 个月；
- 6 个月；
- 1 年。

最低有效收益比例：

\[
c\in\{0.80,0.90,0.95\}.
\]

定义：

\[
N_{i,t}(W)
=
\sum_{s=t-W+1}^{t}
1\{r_{i,s}^{network}\neq NA\}
\]

以及：

\[
Coverage_{i,t}(W)
=
\frac{N_{i,t}(W)}{W}.
\]

只有满足：

\[
Coverage_{i,t}(W)\ge c
\]

的股票才能进入网络候选节点集合。

---

### 5.2 最新日期网络节点覆盖

以 2026-09-03、\(c=0.90\) 为例：

| 窗口 \(W\) | 最低有效天数 | 可用股票 \(p\) | 当前股票池覆盖率 | \(p/W\) |
|---:|---:|---:|---:|---:|
| 60 | 54 | 5176 | 99.25% | 86.27 |
| 120 | 108 | 5170 | 99.14% | 43.08 |
| 252 | 227 | 5125 | 98.27% | 20.34 |

因此：

\[
\boxed{
\text{即使要求 90\% 有效同步收益，仍可保留约 98\%-99\% 的沪深股票}
}
\]

说明数据缺失并不是限制全市场建网的主要问题。

---

### 5.3 \(c\) 的敏感性较低

以 \(W=252\) 为例：

\[
\begin{aligned}
c=0.80 &: p=5144,\\
c=0.90 &: p=5125,\\
c=0.95 &: p=5109.
\end{aligned}
\]

从 80% 提高到 90%，仅减少 19 只股票；

从 90% 提高到 95%，仅进一步减少 16 只股票。

因此：

\[
\boxed{
c=0.90
}
\]

可以暂时作为合理的基准完整度要求：

\[
\boxed{
\text{在数据质量与节点覆盖之间取得较好平衡}
}
\]

而 \(c=0.80\) 和 \(c=0.95\) 可作为后续 robustness。

---

### 5.4 Pairwise overlap 不是主要障碍

进一步对最新窗口中符合 \(c=0.90\) 的股票随机抽取 50,000 个 pair，检查共同有效收益比例。

结果显示：

#### \(W=60\)

\[
Mean(CommonRatio)\approx0.998
\]

\[
P(CommonRatio\ge0.90)\approx99.99\%
\]

#### \(W=120\)

\[
Mean(CommonRatio)\approx0.996
\]

\[
P(CommonRatio\ge0.90)\approx99.95\%
\]

#### \(W=252\)

\[
Mean(CommonRatio)\approx0.996
\]

\[
P(CommonRatio\ge0.90)\approx99.99\%
\]

因此可以排除一个重要担忧：

\[
\boxed{
\text{虽然单只股票有少量缺失，但 pairwise common observations 并不会普遍严重不足}
}
\]

这意味着后续 Pearson / Spearman 等 pairwise association estimation 在数据覆盖层面是可行的。

---

### 5.5 网络节点集合非常稳定

相邻日期 eligible universe 的 Jaccard 中位数约为：

\[
\boxed{0.9992\sim0.9996}
\]

例如：

\[
W=252,\quad c=0.90
\]

时：

\[
Median(Jaccard)\approx0.999575.
\]

因此：

\[
\boxed{
\text{后续若观察到显著网络结构变化，不能简单归因于节点集合剧烈变化}
}
\]

这为动态网络分析提供了较好的基础条件。

---

### 5.6 核心结论：全市场网络是持续存在的极端高维问题

定义：

\[
\kappa_t(W,c)
=
\frac{p_t(W,c)}{W}.
\]

最新日期、\(c=0.90\)：

\[
\begin{aligned}
W=60 &: p/W\approx86.27,\\
W=120 &: p/W\approx43.08,\\
W=252 &: p/W\approx20.34.
\end{aligned}
\]

即使使用最长的 252 日窗口：

\[
\boxed{p\approx20W}
\]

仍然属于极端高维。

对于中心化后的 \(W\times p\) 收益矩阵：

\[
rank(X)\le W-1.
\]

因此样本协方差矩阵：

\[
\hat\Sigma
=
\frac1W X^\top X
\]

满足：

\[
rank(\hat\Sigma)\le W-1.
\]

例如：

\[
W=252,\quad p=5125
\]

则：

\[
rank(\hat\Sigma)\le251,
\]

最小 rank deficiency 为：

\[
5125-251
=
\boxed{4874}.
\]

并且整个历史样本中：

\[
\boxed{
P(p_t\ge W)=100\%
}
\]

对所有 \(W\in\{60,120,252\}\) 和 \(c\in\{0.80,0.90,0.95\}\) 均成立。

因此：

\[
\boxed{
\textbf{全市场股票关联网络本质上是一个持续存在的 }p\gg W\textbf{ 高维网络估计问题}
}
\]

这将成为后续网络方法选型的重要实证依据。

---

### 5.7 候选边规模

对于：

\[
W=252,\quad c=0.90,\quad p=5125
\]

完整无向网络候选边数量：

\[
\frac{5125\times5124}{2}
=
\boxed{13,130,250}
\]

即单个日期约：

\[
\boxed{1313\text{ 万条候选边}}
\]

说明正式网络不适合直接保留 dense graph，而必须进一步考虑：

- threshold / top-k；
- MST / TMFG；
- sparse precision；
- block structure；
- residualization；
- 其他稀疏化方式。

## 六、今天形成的主要研究结论

### 6.1 数据基础已经能够支撑正式全市场网络研究

今天已经完成：

\[
\boxed{
\text{Historical Universe}
\rightarrow
\text{Market QA}
\rightarrow
\text{Canonical Return Panel}
\rightarrow
\text{Network Feasibility}
}
\]

因此当前不再需要反复停留在基础行情清洗阶段。

---

### 6.2 数据缺失并不是全市场建网的主要约束

在合理的 \(c=0.90\) 标准下：

\[
\boxed{
98\%-99\%
}
\]

的当前 PIT 股票均可以进入网络。

Pairwise common observations 也几乎完整。

因此：

\[
\boxed{
\text{Missing Data / Pairwise Overlap 不是主要问题}
}
\]

---

### 6.3 真正的困难是极端高维性

从：

\[
W=60,\ 120,\ 252
\]

三个窗口均观察到：

\[
\boxed{
p\gg W
}
\]

且该现象贯穿整个历史样本。

因此后续正式方法选型必须考虑：

- 高维协方差估计；
- 正则化；
- 稀疏性假设；
- 行业 / block 结构；
- 共同市场因子；
- 计算复杂度；
- 网络稳定性。

---

### 6.4 暂时不应直接指定 Graphical Lasso 为全市场主方法

Step 4 的结果并不意味着 Graphical Lasso “不能使用”，但说明：

\[
\boxed{
\text{全市场直接估计一个 }5000\times5000\text{ precision matrix 是高度挑战的}
}
\]

因此后续更合理的候选比较应包括：

1. Raw Return Correlation Network；
2. Factor-adjusted Residual Correlation Network；
3. Block / Industry Sparse Precision Network；
4. Lead-Lag Network；
5. Tail / Extreme Co-movement Network。

Graphical Lasso 更适合作为高维 conditional association 的候选 benchmark，而不是在尚未诊断共同因子和行业结构之前直接指定为主网络。

### 1. Raw Correlation Structure

研究：

- 全市场 Pearson / Spearman correlation 分布；
- correlation distribution 随 \(W\) 的变化；
- 极端高相关 pair；
- correlation 网络密度与稀疏化敏感性。

---

### 2. Common Factor Strength

研究：

- 市场共同因子是否主导原始收益相关性；
- PCA 第一特征值及 explained variance；
- 横截面平均相关；
- 市场因子剔除前后的结构变化。

核心问题：

\[
\boxed{
\text{Raw correlation network 到底在多大程度上只是“市场 beta 网络”？}
}
\]

---

### 3. Historical Industry Validation + Same/Cross Industry

在正式研究 Same/Cross 之前，先验证历史行业标签。

之后比较：

\[
\rho_{ij}^{Same}
\quad\text{vs.}\quad
\rho_{ij}^{Cross}
\]

及其：

- 分布；
- 稳定性；
- persistence；
- 网络贡献；
- 时间变化。

---

### 4. Factor-adjusted Residual Structure

建立：

\[
r_{i,t}
=
\beta_i^\top F_t
+
\varepsilon_{i,t}
\]

比较：

\[
Corr(r_i,r_j)
\]

与：

\[
Corr(\varepsilon_i,\varepsilon_j)
\]

判断 factor-adjusted residual network 是否具有更清晰的股票间特异关联结构。

---

### 5. Network Candidate Selection

最终依据：

- 数据结构；
- 高维性质；
- 稳定性；
- 行业结构；
- factor residualization；
- 计算复杂度；

选择进入正式比较的候选网络方法。
